## 1. 依据与边界

依据“产品经理”会话 01a1d3e8-579f-7a21-a371-354a0d5c5b88 及其 V3.6 可操作原型，继承 V3.5 完整需求、V3.6 模型/MCP/Skill、V3.7 三引擎导入与 LAN、V3.8 共享核心与未来终端边界。设计输入摘要见 source/input-baselines.json，原型入口仍为项目根 index.html；原型源码与旧设计图保留。

完整产品 UI 设计覆盖 79 个业务界面，以及 1 个公共浮层分组（16 种浮层），合计 80 个分组、507 张中文画板。原型的 195 个基础状态逐项映射；桌面 264 张，Android 243 张，含原型定义的手机横屏状态。画板与需求关系以 source/scenarios.json 和 acceptance-matrix.csv 为准。

用户在架构会话中明确“先不搞云端”：本地创作、自带模型配置、局域网同步与 Windows 工程导入为当前设计重点；平台云端生成、计费与在线游戏运营相关界面作为后续设计区展示。未来三引擎工程写出与 Apple/平板编辑器只交付扩展入口和布局规则，不宣称已有实现。自带模型仍按用户选择的服务连接，不把本地项目编辑强制绑定云端。

当前研发包 local-core-v1 是无 GUI 的共享核心一期。这套完整产品视觉设计不改写该包的 scope、流程 current_stage、人员批准或开发接收记录，也不把全部界面纳入正在进行的一期实现。

本次只制作设计资产、交互文案和验收方案。未运行项目脚本、编译、测试、扫描、实际模型/MCP调用、设备操作、截图比较或最终构建验收。PNG 是从本次 SVG 设计资产导出的预览，不是 Qt/Android 的运行截图。

## 2. 视觉方向

延续原型蓝白风格，采用清晰的灰蓝背景、白色工作面、单一蓝色主操作、绿色完成反馈和琥珀色待处理提醒。世界和素材允许丰富颜色；编辑器外壳保持安静，帮助用户辨认选中对象、待应用提案和真正完成的保存。

新手入口为“描述想法 → 预览变化 → 试玩 → 导出”。专业工具保留完整能力，通过“更多工具”、对象属性与高级折叠进入。默认不同时展开所有参数。业务逻辑以工作流为权威；对话、画布、表格、导入和同步共同指向同一个项目及事务历史。

设计中的数值、进度、配对短码、日期、服务地址和模型示例均用于排版。example.com 为说明占位，不是实际服务。r128、68% 与导出成功画板是状态设计，不是本次执行结果。

## 4. 桌面布局

基准画板 1440×960 逻辑像素，浅色、中文、系统缩放 100%、字体 100%。左导航宽 192，顶部项目栏高 72，工作区边距 24。顶部保留项目身份、保存状态、试玩和导出；底部保留分支与历史上下文。

编辑器采用对象/图层、中心画布、属性三个区域。面板独立滚动；拖动分隔线只改变工作布局，不修改项目事务。窗口低于 1280 宽时收起对象面板为抽屉；低于 1024 时进入紧凑布局，优先保留中心画布和单一属性面板。不得把面板挤压到不可读宽度。

Qt 端映射同一套设计变量和交互语义，不把网页原型当作 Qt 窗口实现。键盘支持 Tab/Shift+Tab、Enter、Esc、Delete、Ctrl+Z/Ctrl+Shift+Z、Ctrl+S；文本输入和系统快捷键优先。窗口 DPI/跨屏/IME 的实际验证另行安排。

## 5. Android 布局

竖屏画板 390×844、横屏 844×390，均为逻辑尺寸参考。顶部状态区和系统底部手势区由宿主安全区域换算；画板里的固定值不能代替运行时 insets。

竖屏一次显示一个主要任务。底部为对话、画面、工作流、资源、更多；导出从更多或项目操作进入。对象属性放在画布下方或可拖动底部抽屉，抽屉有半屏/全屏状态；关闭抽屉保持选择、输入草稿和画布缩放。

节点图、地图、骨骼和游戏 UI 提供横屏入口。横竖屏切换保留选中对象、当前通行面、视口、未提交草稿和任务状态。横屏将工具放在画布边缘，属性独立滚动。不能把触屏拖动同时解释为画布平移和节点连接；使用显式编辑模式、吸附提示与取消入口。

返回顺序：结束临时选择/连接 → 关闭浮层 → 退出全屏编辑 → 回到上级页面。未提交表单触发保留草稿/保存/放弃选择，不静默清除。系统后台、锁屏与进程重建由任务恢复设计承接，不凭 UI 画板宣称已实现。

移动表单和属性面板超出首屏时滚动，底部主动作在安全区上方保持可达。长名称和说明允许多行；列表省略时详情提供全文。数值、路径、模型 ID 与代码键不按语言翻译。

## 6. 三引擎导入

只有 Windows 提供工程转换向导。可选项只有 Cocos Creator、LayaAir、Godot；支持代际是产品目标，精确子格式以架构与适配器能力表决定。无“其他引擎”“通用工程”或反编译安装包入口。

流程为只读源工程 → 新目标目录 → 内容分析 → 映射/许可 → 转换进度 → 结果对账/待补任务。已转换、替代、待补、排除分别记录，统计须对账。项目创建成功和可运行就绪分开显示。未知脚本只形成待补工作流任务。

重新导入显示旧导入基线、当前 GameGen 手改与新源工程。没有静默覆盖选项；二进制保留版本，删除与引用冲突必须处理。Android 只提供接收后打开项目和查看报告，不提供转换向导。

## 7. 局域网同步

附近设备只显示必要设备名、平台和兼容信息。发现不泄露项目列表。用户选择设备后双端核对短码，再授予项目和操作范围。扫码与手工 IP 只是发现替代入口，身份核对与权限流程一致。

发送前固定快照并显示变化、依赖、空间、方向和目标。传输、校验、提交分别有状态；完整提交之前不能把项目显示为可用。断线后继续原快照，源变化要求重新预览，不能拼接不同来源任务。

冲突以共同祖先比较，不比较设备时钟或 revision 大小决定胜者。同字段、图拓扑、删除/编辑、二进制分别展示；保留双方、选择单侧与取消均保留来源。取消信任终止后续访问，说明已完整接收的副本无法远程抹除。

连接说明解释本地网络权限、网卡、防火墙和 AP 隔离；不要求关闭安全机制，不回落公网、ADB、云中继或平台登录。

## 8. AI、模型、MCP、Skill 与费用

对话发送前可选模型、上下文、工具和 Skill。轮次固定实际配置版本、作用范围、权限和费用来源；设置改动从下一轮生效。提案先校验再应用，人工修改和 AI 修改在同一历史查看。

模型表单把服务来源、API 格式、鉴权、Base URL、模型 ID 分开。OpenAI Chat Completions/Responses、Messages 的 API Key/Bearer、OpenCode Go 等预设沿原需求；设计画板没有验证供应商端点。凭据遮罩，明确显隐、替换、清除与仅本次保存状态。

MCP 包括远程 HTTP、服务明确支持的旧 SSE 和本机 stdio 参数数组。Android 本机依赖缺失必须显示原因与替代入口。工具动作授权列明项目、对象、参数、影响、费用和允许范围，超时不能谎称外部动作未发生。

Skill 显示来源、版本、许可、正文、依赖、附件与更新差异。导入不自动全局启用；正文不授予脚本、文件或网络权限。日志脱敏，记录实际轮次与事务，未返回用量显示待确认。

本机音效模型可用时走本地候选/试听/接收；未安装时提供文件导入。平台付费生成属于后续范围，费用来源、预算、取消请求、供应商状态与结果入库分开设计。

## 9. 四目标导出

目标只有 H5、Android APK、微信小游戏、抖音小游戏。Android APK 是预编译 WebView 壳与 C++ 编译的 WASM 内容方案，具体执行以架构交接为准。无新增 iOS/PC 游戏发行入口。

导出前固定项目快照，检查引用、工作流、离线依赖、目标能力、资源许可和凭据。APK 表单包含应用名、包名、版本、方向、图标、权限与签名引用；签名私钥不进入项目。每目标的能力限制和失败原因可定位。构建成功之后提供产物、快照、文件校验和继续编辑入口，失败保留旧成功产物。

## 10. 四语、辅助使用与主题

本次新视觉资产的固定文字为 zh-CN。原型已登记的 780 个四语场景通过 locale-mapping.csv 全量对应新画板，不把中文画板冒充英文、日文或韩文最终设计图。新页面同样继承四语义务，四语文案审校和实际排版验收均待执行。

英语与韩语布局预留约 35% 文案扩展；按钮允许增宽或双行，表头可固定列宽加横向滚动。用户内容、协议键、路径、URL、模型 ID、消息历史保持原文。将“缺翻译”作为可定位问题，展示实际回退。

桌面基准 100% 和 150% 缩放、Android 字体 100%/130%/200%、中英日韩、TalkBack/键盘、横屏和显示安全区列入最终验收计划。状态不只依赖颜色，图标有无障碍名称，模态框焦点进入标题或首个控件，关闭后还原触发焦点。画布操作提供对象/节点列表与可输入属性作为替代路径。性能和无障碍阈值需实际验证，未在本轮声称达标。

当前浅色主题为视觉基线。深色主题没有在本轮伪造完成；未来单独冻结变量与状态图。本地一期不因缺少深色稿被扩充研发范围。

## 11. 交付与验收记录

507 张 SVG 是可编辑设计源；507 张 PNG 是预览副本。source/screens.json、scenarios.json、render.mjs、overlays.mjs、overlays.json、原型矢量场景和固定示例数据可重建资产；实现人员可以直接导入 SVG 到支持矢量的设计工具，复杂图形与普通控件仍分别实现。

assets.json 记录资源尺寸和来源，字体不打包，图形继承项目原创 SVG/本次原创几何绘制的来源声明；真实权利人尚待确认，没有代签许可。

acceptance-matrix.csv 逐画板关联需求、验收、固定环境、设计哈希、执行状态与负责人。最终构建身份、实际截图、差异关闭、设计负责人批准与双图哈希另行填写。本次不创建假的实际截图或 approvals。
