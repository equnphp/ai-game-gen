# GameGen 交互与状态规范

版本：ui-full-20261117-draft.1；设计定义，execution_status=not_run。

## 完整路径

| 场景 | 正常路径 | 分支与恢复 |
| --- | --- | --- |
| 第一次做游戏 | 项目 → 新建 → 玩法模板 → 对话 → 提案 → 试玩 → 导出 | 缺名称就地提示；保留类型与输入；不要求注册后才能本地创作 |
| 对话修改 | 选模型/上下文 → 发送 → 工具活动 → 澄清 → 预览变化 → 应用 | 断网保留草稿；取消与外部任务终态分开；基线变化进入差异 |
| 画面与规则互改 | 选择对象 → 属性/组件 → 对应工作流 → 对话继续修改 | 稳定 ID 不变；校验失败保留输入；撤销按实际事务处理 |
| 地图与关卡 | 地块/物体 → 高度/坡道/桥面 → 通行面 → 寻路 → 关卡目标 → 工作流 | 不相连通行面定位坡道；空地图给推荐起点；横屏保持草稿 |
| 资源替换 | 导入/生成候选 → 预览/试听 → 来源许可 → 选择入库 → 影响范围 → 替换 | 重名不静默覆盖；缺依赖保留原件；旧版本可回退 |
| 局域网续编 | 发现 → 双端短码 → 授权范围 → 固定快照 → 变化预览 → 传输/校验/提交 → 打开 | 网络隔离给说明；断点恢复绑定原快照；源变化重算；冲突不覆盖 |
| 工程迁移 | 只读来源 → 引擎/版本 → 新目录 → 分析 → 映射/许可 → 转换 → 报告 | 拒绝名单外/未知格式；四类迁移结果对账；重导入三方比较 |
| 本地导出 | 选择四目标 → 参数/签名引用 → 快照校验 → 构建 → 产物 | 不支持能力定位来源；失败保留旧包；中断查询已完成阶段 |
| 恢复与历史 | 历史 → 差异 → 恢复点 → 新工作副本 → 继续编辑 | 空间不足停止写入；格式不兼容查看升级说明；不覆盖旧版 |
| 扩展配置 | 添加模型/MCP/Skill → 校对来源与权限 → 限定范围 → 下一轮生效 | 凭据不随项目走；手机缺本机依赖可改远程；配置与运行结果分开 |

## 状态行为

| 状态 | 显示内容 | 允许动作 | 返回/恢复 |
| --- | --- | --- | --- |
| 首次使用 | 产品价值、一个推荐起点、短引导 | 创建、打开、跳过引导 | 回到项目列表 |
| 正常 | 当前上下文、可用操作、保存与任务状态 | 完整范围内编辑 | 按页面导航保留选择 |
| 加载 | 当前阶段和可理解进度；未知剩余时间不猜测 | 查看任务、合法取消 | 结果与原输入分开保留 |
| 空态 | 说明缺什么，提供单一创建/导入入口 | 添加、用模板 | 添加后进入该对象上下文 |
| 无结果 | 现有筛选条件 | 清除或修改筛选 | 不修改项目 |
| 需授权 | 具体服务或本地权限缺失 | 授权、使用替代本地路径 | 成功后返回原动作 |
| 权限不足 | 请求目标、实际范围、拒绝原因 | 查看范围、重新选择、取消 | 不扩大成全盘权限 |
| 远程离线 | 需要网络的动作与本地可用动作 | 保留草稿、本地编辑、重试 | 外网断开但 LAN 可达时继续同步 |
| 错误/超时 | 失败阶段、可定位原因、已完成状态 | 修正、查询原任务、重试 | 不盲目重复外部写入/扣费 |
| 重复操作 | 原任务/事务身份和已有结果 | 查看原结果 | 不生成重复副本或重复结算 |
| 中断 | 已完成阶段、未提交内容、原快照 | 继续、重新预览、取消 | 校验输入身份后恢复 |
| 成功 | 实际产物/提交版本与下一步 | 打开、查看变化、继续编辑 | 成功态设计不代表本轮真实完成该业务 |
| 冲突 | 共同祖先、两侧变化、引用影响 | 按类型选择、保留双方、取消 | 形成新的合法项目事务 |
| 配对过期/拒绝 | 配对状态和未建立授权 | 重试或返回设备列表 | 不读取项目内容 |
| 源快照变化 | 原任务快照、新来源摘要 | 保留旧任务或重新预览 | 不混合两次数据 |
| 校验失败 | 受影响资源与未提交标记 | 重传缺块、查看清单、取消 | 旧版本继续可用 |
| 空间不足 | 需要空间和目标位置（实际值待宿主返回） | 清理、换目录、稍后继续 | 不以估算声称已持久化 |
| 版本不兼容 | 双方格式与所需能力 | 查看能力表、升级、另存兼容副本（已支持时） | 不静默删除未知必需字段 |

## 公共浮层与输入

16 种浮层均有桌面和手机画板：本轮模型、上下文、未保存离开、删除对象、删除被引用资源、替换资源、恢复确认、取消任务、MCP连接方式、Skill更新、权限扩大、配对扫码、本地地址、读写能力、费用来源确认、签名凭据。

对话框只阻断其作用范围；Esc/系统返回按操作安全性关闭，运行中任务需提供明确取消入口。焦点受控并还原。外部副作用和已接收副本不能以“本地撤销”谎称回滚。长文案允许滚动，不缩小关键正文来塞入首屏。

节点编辑提供显式“连接”操作；端口展示类型、执行域、同步/异步与错误分支，非法连接保留原图并解释原因。移动端用选择后操作栏替代悬停专属入口。桌面右键菜单和手机更多菜单拥有等价操作。

表格支持固定 ID、逐字段校验、可复制文本和显式横向滚动。地图同一逻辑格的地面、桥面和高度分开标识。时间轴区分预览播放、工程提交、运行时状态；暂停/重置不生成项目修改。

## 真实验证边界

本文件定义交互预期，未实际操作产品或设备。四语原型的 780 个场景通过 locale-mapping.csv 指向对应中文视觉稿；不会将同一张中文图登记为四种语言的最终截图。详细质量策略仍由 quality_mcp 独立维护。
