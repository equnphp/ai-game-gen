# 地图、物理与技能共用的空间界面规则

版本full-ui-details-20261117-draft.1；2026-11-17。来自MAP-005/008/009/010及主规格物理/战斗约束。本文件只定义产品显示/校验义务，不新增另一套核心坐标Schema或自由3D能力。

|概念|界面应提供|校验/行为|
|---|---|---|
|逻辑平面位置|对象/格位X/Y、所属地图/通行面，单位来自该项目空间契约|投影/缩放/分辨率不改距离、占地、攻击范围与计时|
|通行面与高度基准|明确面引用、逻辑高度基准、相对/世界表达的当前模式及换算预览|具体表示沿锁定地图/核心契约；各模块不自造Z语义|
|物理/技能垂直范围|最小/最大高度或偏移、单位、基准面、对象/阵营/能力过滤|min<=max，引用与单位一致；屏幕重叠不等于碰撞/可命中|
|仅视觉偏移|单独的画面上移/装饰偏移模式与数值|不切换所属通行面，不改变碰撞/导航/逻辑高度|
|改变逻辑地形/支撑面|高度/连接/对象随面移动或保留高度的明确选择，影响预览|地形/对象/导航/事件一致更新；取消或失败不留下半次变更|
|脚点、占地、碰撞与遮挡|分别可查看/编辑，角色/建筑方向映射与挂点一致|大树树冠不自动全图阻挡；飞越屋顶按真实高度与部件关系排序|
|跨层移动/事件/技能|连接入口出口与允许能力，当前编辑面和目标层持续可见|无连接不假通路；桥上经过不触发桥下事件；不是凭屏幕Y自动换层|

新手先看到当前层/面、可走与放置反馈；空间基准/区间/换算在相关高级属性打开。参数未被能力契约支持时明确未支持，不能假称底层已实现。坐标/高度数值范围由实际类型/能力表限制，不在本包虚构最大值。

涉及操作面：SUR-GM-008/009/010/015/037、SUR-ST-033及相关物理/命中/相机预览。画稿中各面必须使用一致名称/单位/基准，状态示例同时包含桥上/桥下及仅视觉上移。
