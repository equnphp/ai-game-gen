## 判断标准

1. 需求有页面链接，只能说明可追溯，不能说明所需编辑能力已有视觉设计。
2. 页面标题、列表卡片、通用属性栏和通用状态提示不能替代专业工作台。
3. 区分编辑器UI、游戏内UI模板、系统/服务授权界面、运行状态和后续联网运营。
4. 页面、标签页、抽屉、弹窗、字段分支、横屏/字体/语言状态不混为独立页面数量。
5. 优先复用选择器、版本比较、任务中心、组件管理等共享交互，领域语义仍需专用内容。
6. 静态读稿发现的是设计缺口；没有因此执行构建、测试、扫描、截图对比或设备操作。
