# 可跳过的新手引导：详细产品与界面增补

版本：onboarding-20261117-draft.1；2026-11-17。来源：用户“加一个新手 引导，可以跳过”。这是 full-ui-details-20261117-draft.1 的增量规格，细化 SUR-GL-003 学习入口、SUR-GL-002 工作区偏好和 JNY-01 首次创作，不覆盖原稿或根 M1 开发清单。当前为 L 本地产品 UI 需求；planned_not_drawn / not_run。

## 1. 目标、取舍与默认规则

零开发经验的用户能知道下一步做什么，并完成一次“修改→保存→试玩”。用户可直接进入工作台；引导不成为创作前置条件。选择短任务式可选引导，逐步显示当前所需工具；不采用强制讲解所有面板的长流程。

- 首次进入给一次欢迎卡：主按钮“开始引导”，同级可见次按钮“跳过，直接创作”。关闭按钮与 Android 返回同跳过，单次点击退出，不再弹确认框。
- 欢迎卡无倒计时、无强制登录、无经验问卷。使用编辑器当前语言；首次语言选择沿现有语言设置，不另造一份设置。
- 跳过后立即保留正常创作入口，不锁模板、工作流、高级工具或导出。只在当前可见工作区显示一次非阻断提示“已跳过，可在帮助与学习中重新打开”；不在后台/下次启动补弹。
- 本地偏好记住已跳过、进行中、已完成。更新版本、切换项目、导入或 LAN 收到项目不会重新强制弹出。新增课程只显示学习中心的新内容标记。
- 后续可从项目首页“帮助与学习”、工作区帮助菜单、全部工具 SUR-GL-003 重新进入。入口用“新手引导”，不要求用户搜索术语。
- 基础教程内置文字、示例、资源许可说明，离线可用；不要求模型、Key、MCP、Skill、云积分或安装第三方服务。缺运行组件说明原因，可继续读、跳过操作或返回工作台。
- 讲解不触发业务操作。引导用正常工具和同一核心事务，不直写项目、不自创工作流或保存机制。

## 2. 首次完整路径：一个可玩的本地小示例

用户主动开始才创建独立练习副本。默认推荐内置“收集星星”2D 示例，明确只是学习示例，不预设用户今后只能做此类型。可选择“用我刚创建的项目学习”；该路径不自动放入示例对象、不替换内容，找不到适用对象则给选择对象/改用练习副本/跳过本步。

开始前显示练习名称、保存位置、内置资源和“会新建独立练习项目”的一句说明。已有正式项目有草稿时，沿既有离开/保存合同处理，不因开始教程丢草稿。双击开始只创建一次；关闭/跳过不自动删除练习项目。首次欢迎即跳过不创建示例、不导入资源、不提交工程事务。

|步骤|屏幕上的目标与控件|完成依据|可替代/跳过|
|---|---|---|---|
|G01 认识工作区|只指向场景、属性、对话和试玩的当前位置；一句“在这里改游戏，再试玩”|用户点“明白了”|上一/跳过本步/结束引导，不强制打开每个面板|
|G02 改一个外观|选示例角色，改名字/颜色，或选择内置角色图；对象位置和引用可直接定位|用户通过正常工具完成合法修改并确认当前值；原已满足也可“已了解”|无适用对象时选对象或练习副本；不强制导入个人文件|
|G03 改一个行为|用“当碰到星星→分数+1”简易卡，改可理解的数值；可查看对应工作流|对应工作流变更实际受理并持久化；只打开图不算改好|已有项目不能覆盖原规则；可仅看讲解或跳过，记录为已了解/已跳过|
|G04 了解对话修改|给可编辑示例文本“把角色的移动速度调慢一点”，先解释变化预览→采用的关系|可选看本地固定示例，或用户主动发送真实请求并实际采用合法提案|默认演示不调用模型；预录示例显著标“教学示例，不是本轮AI结果”；真实调用需来源/费用/权限规则，离线或无模型可直接跳过|
|G05 保存并试玩|指向现有保存/试玩，保存当前合法修改→核心确认→固定快照试玩；展示所玩版本|保存 durable 已确认且实际进入试玩；试玩失败不记操作完成|非法草稿先修，或用户明确选最近已保存版并标不含草稿；未知结果查询原请求，不重复提交|
|G06 回到编辑继续创作|停止隔离试玩，定位回原对象；显示工程名、保存状态、下次入口|已退出试玩并回到实际工作区|总结分清完成、已了解、已跳过、待处理；可继续自由创作/重看步骤/进入选学课程|

主流程不强制发布、配置签名、生成图片或花费积分。最后给“继续创作”为主动作，“了解导出”为选学动作，导出仍按现有四目标独立预检和产物流程，不自动打包或上传。

“引导已结束”与“已完成全部操作”分开。全部步骤都有去向便可结束阅读；只有需要实际操作的步骤有真实对应事件，才能显示操作已完成。跳过与“已了解”不计入实际完成率，不以停留秒数或自动脚本代做宣称用户已学会。

## 3. 逐操作面设计补充

这些是原工作区中的卡片/浮层/抽屉状态细化，不新增六个顶层导航页，也不把旧213面数量改成新的实际画稿数量。机器索引见 onboarding.json。

### GUIDE-VIEW-01 首次欢迎卡

位置：项目首页顶部卡片，窄屏可用轻量面板；不遮住“新建项目/打开项目”。字段：标题、目标一句话、内置离线说明。动作：开始引导、跳过直接创作、关闭。禁止把跳过做灰色小字或藏进更多；按钮可见、可键盘/读屏访问。升级/已有用户从帮助主动打开同一入口时，标题显示“开始/继续新手引导”，不再次假装第一次使用。

### GUIDE-VIEW-02 帮助与学习中心

沿 SUR-GL-003 的学习分区。字段：课程名称、能学到什么、入门/选学、当前设备进度、可用性、课程搜索；每条显示未开始/进行中/已跳过/已结束及实际完成概览。动作：继续、从头重看、选步骤、打开练习、在当前项目学习、关闭自动操作提示。

“从头重看”只重置该课程进度，不删除项目/撤销已提交修改；先说明重看范围。如果选择重新练习，明确新建副本并沿正常创建路径。找不到原练习项目给打开其他项目/新建练习，不能偷偷创建第二份。学习中心没有匹配结果时保留筛选与清除按钮；课程不可用显示具体缺组件/目标平台原因。

### GUIDE-VIEW-03 操作提示与步骤面板

桌面：侧边步骤面板+靠近目标的简短提示；Android：底部步骤卡，避开键盘/安全区和所指按钮，不用全屏遮罩锁住操作。字段：步骤名、当前序号/总数、一个目标、当前完成/保存状态、目标定位与简短说明。动作：定位操作、上一步、下一步/已了解、跳过本步、结束引导；主下一步按真实条件启用，另有始终可用的跳过。

提示不得吞掉底层正常点击、拖拽、滚动或读屏；模态权限/危险操作确认优先。定位不到目标时不显示悬空箭头，改为步骤卡说明和可选定位/选择对象。用户手动切页暂停跟随，返回相关工具再继续，不连续抢焦点。系统返回/关闭当前提示结束本次引导，不拦正常导航。

### GUIDE-VIEW-04 跳过/退出后的反馈

显示一次非模态提示，含“重新打开”入口。停止引导的遮罩、跟随定位和教学计时；保留已提交修改、草稿、选区、练习项目。退出教程不自动取消已发送模型/构建/保存/资源任务，也不撤回外部结果；实际运行任务交给原界面和全局任务中心，可按原有能力取消。返回工作区后焦点回到用户原操作处。

### GUIDE-VIEW-05 结束与下一步卡

主标题按实际结果为“已完成入门操作”或“本次引导已结束”。列出已实际完成、已了解/已跳过、未完成原因；显示练习项目可继续编辑入口。主动作继续创作；次动作重看某步/选学导出/更多课程。无强制购买、强制评分或自动开启高级面板。关闭后不每次启动弹庆祝卡。

### GUIDE-VIEW-06 引导偏好与上下文轻提示

沿 SUR-GL-002 设置→帮助与引导。两个独立偏好：“首次操作时显示简短提示”（默认开）与“显示学习进度”（默认开）；主引导跳过后不再自动进入整段教程，首次功能提示只在用户真正打开该工具时显示可关闭的一条。其上显著提供“关闭所有自动操作提示”，关闭后仅保留用户主动点帮助的入口。

单条“本功能不再提示”只抑制该功能；总开关影响所有自动轻提示，均不影响真实错误、权限、费用或危险操作说明。用户可通过“重看新手引导”主动进入，即使自动提示关闭也允许。重置引导记录需列明仅清本机学习进度和提示偏好，不改游戏；不随恢复工作区布局默认清除。

## 4. 选学课程与高级功能出现时机

在学习中心完整保留，首次仅推荐当前任务一项，不串成强制长教程。

|课程|何时推荐|讲解的完整小闭环|
|---|---|---|
|对话与工作流|主动点对话/行为编辑|描述→澄清→预览→采用工作流→手调→再对话；手机一键横屏后可切回|
|地图与关卡|打开地图/关卡工具|地面/对象/可走区→出生点/目标→试玩；斜45度与多通行面按需课程|
|RPG|选择RPG模板/模块|角色/技能/物品→NPC/任务→对白→奖励/存档|
|SLG|选择SLG模板/模块|建造占地→资源/生产→科技/单位→时间/回合→试玩|
|物理与特效|打开物理/粒子工具|选预设→碰撞/重力或发射量→隔离预览→应用；高级矩阵/曲线单独选学|
|动画与音效|打开动画/音频工具|帧/骨骼动作或内置音效→绑定事件→试听试玩；网格/权重/混音按需|
|接口与联网配置|主动进入接口工具|导入文档→可编辑Schema/协议/工作流→本地模拟；真实联网/R运营明确后续能力，不假连接|
|设备接力与项目导入|主动打开LAN或Windows导入|本地配对→范围→变化→同步；Windows三引擎转换和Android查看报告分别讲|
|导出游戏|主动点导出或选学|H5/APK/微信小游戏/抖音小游戏选择→预检→本地生成→定位产物；不自动上传|
|模型、MCP与Skill|主动打开扩展设置|地址/鉴权/来源→安全范围→目录/内容预览→本轮快照；无暗中连测/调用|

这些是可选择的引导课程，不宣称对应功能已实现；能力表显示未交付/后续R时，课程可只读说明，执行按钮显示真实原因。

## 5. 状态、持久化与跨端

进度是本机编辑器学习偏好，和工作流/项目数据分开，不作为项目必填字段，不随工程包、导入、LAN资源同步或发布产物携带。项目关联只在本机指向练习/对象，解绑/项目删除不影响他人副本。Windows与Android各自记进度；语言切换不重置，项目切换不重复欢迎。

课程状态：not_started / in_progress / skipped / ended / completed。步骤状态：not_started / active / completed / acknowledged / skipped / blocked。教程结束不清空未完成原因；skipped和acknowledged不冒充completed。进度按 guide_id+version+step_id 稳定保存，语言不用作状态身份。已删除的课程步骤映射为历史记录，新增步骤只标新内容，不强制重启；用户主动继续时定位最近仍适用一步。

|场景|展示与动作|恢复规则|
|---|---|---|
|首次/未开始|一次欢迎卡，可开始或跳过|跳过记录本机偏好，后续帮助可进入|
|正常/进行中|当前一个目标、进度和退出入口|真实事件满足才推进，允许已了解/跳过|
|读取/创建/保存中|真实阶段、原任务绑定、可结束引导|结束不重复提交或伪取消任务|
|无适用项目/对象|选对象、独立练习、跳过|不自动把示例内容塞入正式工程|
|课程搜索无结果|保留查询，清筛选|不当成课程丢失或自动联网检索|
|未登录/模型未配|本地基础教程照常；真实AI动作显示配置/本地替代|无强制账户、无静默匿名降级或自动开通付费|
|目录权限拒绝/只读|显示具体限制，选位置/只读了解/跳过|保留旧工程，不通过引导绕权限|
|离线/组件缺失|内置说明可读；区分缺本机组件与无网络|可跳过运行步骤，不宣称已试玩|
|错误/超时/结果未知|具体阶段、原请求/任务查询入口|保持当前步与输入，不盲重放、扣费或重复创建|
|重复点击/重开|复用同次创建/保存身份，询问重看或继续|重复打开只一个引导实例，跨窗口引导以当前活动工作区为准|
|旋转/锁屏/进程重建|保存步骤/对象稳定ID/草稿与任务身份|恢复后非阻断“继续上次引导”；不重发业务请求；进度写失败显示“本次进度未记住”不假已保存|
|结束/已完成/已跳过|真实概览，继续创作/重看|不自动删练习/撤销项目或强制再次弹出|

手机工作流高级图由用户点击切横屏；引导跟随布局，切回竖屏后仍同一步/图选区/草稿，不强制保持横屏。软键盘出现时提示卡压缩或折叠，输入焦点优先。桌面缩放/窄窗与大字号采用可滚动卡片，跳过和退出始终可达；键盘可遍历，Esc与关闭一致，读屏公布步骤名和状态。减少动态效果时取消箭头闪动/镜头动画；无按秒倒计时步骤。

## 7. 验收目标与衡量边界

详细验收ID见 .product-mcp.json 与 onboarding.json：GUIDE-REQ-01—04 / GUIDE-AC-01—12。重点是任意时点可跳过、离线无需付费、新手与正常业务同源、真实状态与进度、四语/旋转/无障碍，以及教程退出不影响已发出的业务任务。

可选目标：未来在知情同意的零经验参与者任务观察中，以内置示例统计“主动开始到第一次保存并进入试玩”的中位数目标不超过10分钟；这是初始产品目标，尚无样本、基线或测量。跳过、读懂、实际完成分别统计；教程用时不等同游戏创作总耗时。耗时、步骤状态可在本机提供给用户自查，不自动上传遥测。不得靠替用户执行/隐藏错误/强迫付费来达标。

本包仅产品和界面交接文档，没有新增画板、可运行新手引导或客户端功能，没有执行测试/截图比较/设备操作。真实产品/架构/UI评审待登记；execution_status=not_run，quality_verified=false，release_permitted=false。
