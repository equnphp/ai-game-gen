## 2. 模块责任及依赖

- C++ Core：项目/领域校验、事务、历史、durable状态、资源/任务权威。尚未存在的Graph/Runtime能力必须有独立架构/产品包，不由教程补假字段。
- Rust LocalUXService：设备偏好、课程状态机、单写者、真实业务回执观察、练习创建journal和版本恢复。它不重实现游戏规则。
- React表现层：学习入口/卡片/焦点/语义目标/四语/适配；同一正常编辑工具完成实操。对话ChatReadModel按独立来源投影，不能把聊天完成当项目已保存。
- 正常ActionCoordinator与SaveCoordinator：分类副作用、权限、提案/CAS、去重、保存栅栏、固定快照与真实预览；Agent/手改/引导共用。
- 受管PrivacyPolicy：所有受管远程模型/MCP/报告/自动摘要出站执行localOnly；普通授权不是解禁。不能隔离的任意本机工具不获得该组合能力。
- UI负责人按真实产品包准备画稿和版本化.design交接；独立quality负责系统性质量文案，coding只负责改动单元与主/失败路径基础自测文案。
