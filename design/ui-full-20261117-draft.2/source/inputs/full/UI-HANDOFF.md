# 产品细节需求→UI绘稿交接

版本full-ui-details-20261117-draft.1；2026-11-17。本包将完整产品需求展开到实际操作面，作为新设计版本输入。没有替代正式产品/架构/UI评审，也没有将本地M1无GUI范围改成全量编辑器实现。

## 1. 本包覆盖什么

覆盖编辑器的工作台、对象详情、编辑模式、选择器、属性抽屉、确认对话框、后台任务、错误恢复和跨端返回。游戏内HUD、菜单、背包、对白等作为游戏UI编辑器可修改模板与预览内容；创作者未来自定义的每一种游戏画面通过这些工具创作，不能把编辑器页面数误当所有游戏画面。

原有79业务页和公共浮层组仍为导航基础。各SUR是具体用户操作面，不是必须新增的顶级页面。相同任务优先合并标签/模式/抽屉，但各自字段、动作与状态不能消失。

## 2. 绘稿输入与约束

1. 先读README、GLOBAL-INTERACTIONS、PROGRESSIVE-DISCLOSURE和USER-JOURNEYS，再按studio/gameplay/workflow及CHAT/GLOBAL操作面绘稿。字段默认/校验/visible_when必须落实，不再只写高级设置。
2. 对复合字段，表中subfields是需要画出的子控件；纯几何/曲线/网格控件也有工具/参数定义。不能把存在字段名当控件已画。字段组与子控件不应机械相加为必填数量。
3. 开关/按钮/输入/列表/树/图端口/时间轴组件状态按CMP继承；具体领域的缺资源、非法形状、目标失效、取消过晚、结果未知等仍要有内容、动作、退出与恢复。
4. 新手默认展示按PROGRESSIVE-DISCLOSURE，不因专业参数多而挤满首页。required指提交合法性，不等于必须由新手手工填写已有预设/只读字段。高级用过须提示，收起不清数据。
5. 现有蓝白tokens与参考尺寸延续；桌面/手机布局各自适配。尾部字段、软键盘、安全区、长文字和中文/英/日/韩稿不能只用说明代替；实际新稿四语覆盖单列。
6. 以FIXTURE-PLAN的虚构示例画稿：动画状态显示过渡参数，骨骼显示网格权重，音频显示混音总线，历史是两版本，AI/LAN/重导入是各自三方。禁止继续复用水晶条件/手机跳跃值填充所有页。

## 3. 当前技术与平台

当前表现层沿editor-web-v1-draft.2：React/TypeScript、Tauri薄宿主、共享C++领域核心。旧Qt/Flutter实施映射不再用于当前UI开发约定。UI不直写库，模型/MCP/Skill不绕过受限领域工具。

Windows/macOS/Linux桌面编辑器与Android语义共用；Windows源工程转换仅Cocos Creator/LayaAir/Godot，Android只接收和看报告；LAN本迭代限定Windows/Android。游戏仍H5、WebView+C++WASM APK、微信小游戏、抖音小游戏。

localOnly约束不因上下文勾选、工具权限、自动摘要/诊断或未来R入口而失效。本机任务不依赖云登录；外网断开但LAN可达时本地同步仍按能力工作。

R是真实联网/平台云端后续：完整定义和本地配置/模拟可以保留，不能把生产请求/部署/计费显示成当前可执行。F是未来Writer/Apple/平板扩展约束：目标方向确定，具体版本/系统矩阵另包，不要求当前实现，也不新增游戏发行目标。

## 4. 交付新设计时应回写

- 为每个SUR/字段/动作/领域状态绑定新画板或明确复用组件与展示条件；为全部原入口、67PSR和24家族更新追溯。
- 记录桌面/Android布局、横屏/软键盘/返回、焦点和四语状态，给新版本/源稿/预览摘要；不能以同一中文图算四语。
- 方案合并可做，但写明被合并SUR在哪个具体标签/抽屉承接；没有承接的项目保留未完成，不用编号链接直接关闭。
- 旧画稿、旧审阅与本包都保留；新需求影响原稿需新版本。真实角色审批绑定实际版本与hash，不由工具或助手代签。

本轮仅需求编制；新画板/可运行原型/客户端代码均未生成。execution_status=not_run、quality_verified=false、release_permitted=false。文档检查就绪不等于实际设计、运行或发布完成。
