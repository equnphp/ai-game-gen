## JNY-01 零经验用户第一次创作

- 归属：L；入口：项目工作台首次使用。
- 路径：选玩法模板/空白 → 选视角与本地模式 → 用样例或自有素材 → 在对话或简易卡改外观/一个行为 → 审阅合法变更 → 保存当前合法修改后固定快照试玩 → 退出试玩后继续修改并保存 → 选游戏目标 → 预检并本地导出。
- 分支与恢复：未配模型可用模板/手工路径；缺素材可选内置/占位；缺本地组件定位修复；任何失败保留项目和输入。 试玩入口见SUR-GL-008：非法草稿先修或明确选最近已保存版，不能无声丢弃修改或自动运行旧版。
- 需求：REQ-001、REQ-012、REQ-017、REQ-033、REQ-034。
