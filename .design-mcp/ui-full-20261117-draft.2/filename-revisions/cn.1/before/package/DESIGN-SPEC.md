# GameGen 视觉规格 · draft.2

本版从产品详细字段和状态补充实际画稿，版本独立于 draft.1。具体输入哈希见 source/input-baselines.json。每个产品 SUR 操作面的字段、动作、状态保持原稳定标识；不把源文件中的 planned_not_drawn 直接改为已批准。

## 平台与构图

桌面基准 1440×960：184px 导航、68px 顶栏；中心承担编辑、预览、比较和图形交互，右侧属性按当前选区呈现。普通页在 208px 之后布局，宽屏不把工作区压成表单。Android 基准 390×844：系统栏、安全区域、44px 最小操作高度；画布与单对象属性分层，全部属性另有可滚动长图。完整属性稿的高度代表滚动内容，不代表设备物理屏高。844×390 横屏和键盘避让用引导/对话的具体变体示意；其他复杂编辑器的横屏和多窗口尚待实现阶段细化复验。

工程展示层为共享 React/TypeScript，Tauri 只承载宿主能力，领域计算走 C++ 共享内核。不能沿用旧 Qt/Flutter 前端映射。Android 的系统文件授权和返回行为通过平台适配；macOS/Linux 的原生宿主和细节不据桌面稿推定通过。

## 视觉变量

浅色：背景 #F5F7FB、文字 #172B4D、次级文字 #6A7B93、主操作 #246BEE、选中底 #EDF4FF、边框 #E2E9F2；成功 #16816B、警示 #B7791F、错误 #D84C62。间距 4/8/12/16/20/24/32/40/48；输入圆角8、卡片12、对话框16。正文13、说明11、标题23；Android 主要标题20。字体 Microsoft YaHei UI / Microsoft YaHei / system-ui；未打包商业字体。中文字体放大和其他三语长文需按最终构建逐页验证。

控件、列表、表格、树、引用选择、颜色、步进数值、开关、曲线、时间轴、矩阵有独立视觉；组合类型 + 展开为多个操作控件。字段组和子控件保留父子关联，完整属性稿展示高级字段、验证摘要和全部源动作，避免只在说明中列字段。标签必须持续可见；错误保留输入并定位字段，不能静默清空。

## 专业工作区

- 骨架/蒙皮：可见骨骼、网格三角形、选点、刷子范围与权重；IK、静止姿态和插槽分开。
- 动画/音频：轨道、关键帧、曲线、波形与范围；混音总线有各自推子、电平和静音/独奏位置。
- 物理/粒子：碰撞形状、顶点、分组矩阵、关节两端；粒子发射预览和生命周期曲线。
- 地图/玩法：地图图层、高度/路径/占地；RPG、SLG、战棋、卡牌区域、节奏四轨、竞速检查点使用相应表达。
- 图编辑：工作流、对话、行为、动画状态、科技和配方图保留各自节点语义，调试显示断点/当前节点。
- 比较：历史比较为两版本；AI 提案、接口重导入、引擎重导入和局域网合并为三方比较，并保留来源与当前上下文。

示例游戏名“星溪冒险”，模型“我的模型服务”、接口“角色数据服务”、设备配对数据均为排版夹具。凭据遮罩，不含可用密钥；示例行不代表真实工程数据或已测支持。

## 渐进披露与新手

新手默认展示当前任务必需项，专业功能可从全部工具、全部属性或高级入口进入，不能删除已使用高级值。引导欢迎同时给“开始引导”和“跳过，直接创作”。每步都有定位操作、跳过本步、结束引导；明白了仅记 acknowledged，跳过仅记 skipped。结束引导不取消业务任务，也不伪记完成。学习中心可恢复、重开示例、关闭自动提示；搜索无结果与课程空态分开。基础引导离线可用，不强制模型、Key 或积分。

## 图层与动效

正文→选区→浮动工具→属性抽屉→对话框→权限/阻断提示→系统键盘。点击外部只收起非破坏浮层；确认框不得遮住保留草稿/取消入口。悬停/焦点约160ms，面板约220ms；减少动态效果时移除非必需移动，不移除进度文字。键盘避让保留输入区和主要恢复按钮。

## 独立素材与授权

assets/icons.svg 为24px矢量图标符号；assets/character-rig.svg、map-isometric.svg、particle-effect.svg 是独立示例视觉，不作为业务功能整体截图切图。按钮、文字、卡片、布局应按tokens和组件实现，不可整页贴图。SVG 使用可编辑几何和文本；素材为本包生成的几何示意，权利人确认待项目负责人完成。系统字体只引用，不分发字体文件；无外部照片、商标或生成模型图片。
