# 交互补充与交接边界

逐操作面的入口、前提、动作效果、确认/撤销/恢复，见 source/surfaces.json 及图库来源面板。共享规则继承 source/inputs/full/GLOBAL-INTERACTIONS.md 与 PROGRESSIVE-DISCLOSURE.md；此文件补充布局和实现注意事项。

1. 导航保持项目、来源、选区、筛选、树展开、画布及播放位置。返回顺序：临时操作→浮层→详情→原入口。切换项目先处理未提交内容；异步结果绑定发起时的项目、对象、版本。
2. 修改过程：草稿→校验→提交→持久化确认。显示真实成功/失败，不以请求已发送当作保存完成。存储失败保留输入；“放弃”只处理当前未提交输入。
3. 复杂属性正常稿展示当前任务，完整属性稿覆盖全部字段和源动作。数值、单位、范围、引用类型、数组顺序、显式空值和高级显示条件按源字段契约实现；图上示例值不是默认业务规则。
4. 对话讨论/执行分开；计划不执行，工具权限请求绑定明确对象和范围，追问保留草稿。AI 提案先比较再选择接受；部分接受、保存失败与结果未知单列。停止请求发出不等于已停止，迟到结果不得自动写入。
5. localOnly 对象不进入远程模型/MCP；手动加入上下文不授予上传例外。显示阻断原因和本机/手输替代；源素材许可、费用预算与远程能力可用性分开。
6. 长任务只显示真实可知阶段和量；取消请求、后台运行、任务终态和清通知分开。查询未知结果时复用原任务ID，不盲目重发。
7. 引导只提供提示与定位，不自动触发编辑、发布、连接、安装或删除。跳过、退出、恢复和已完成分别持久化；正在运行的业务任务不因关闭引导而取消。
8. 手机属性面板可以独立滚动；大字段、完整动作和长错误消息不得被底部导航或键盘遮住。输入法组合期间不得发送，返回先收键盘。横屏按中心任务优先，保留选区与草稿。
9. Windows 转换入口白名单仅 Cocos Creator、LayaAir、Godot；Android 接收 GameGen 工程/报告，不提供原引擎转换功能。源工程只读；导入先能力报告和差异审阅，重导入不得覆盖已修改值。
10. 输出 H5、WebView+C++WASM APK、微信小游戏、抖音小游戏；联网平台能力和未来能力在图库标 R/F。设计不证明平台SDK或运行支持已完成，不改变当前开发迭代范围。
11. 鼠标拖拽提供数值/列表等替代；触摸用选中工具栏和长按，快捷菜单可键盘到达。焦点有可见描边，状态使用图标+文字；减少动态效果遵守系统偏好。
12. 所有源状态均有专门画稿，完整属性另有展开稿。尚需产品负责人逐项确认视觉语义、实际项目数据、用户交互和全部平台表现。设计出图不关闭上游缺口或等同可运行实现。

13. 学习操作完成与profile进度落盘分别呈现。写失败只提示“学习记录未记住”，不要求重复已完成业务。未来schema保留原文件；重复开始激活已有引导，不造第二份练习。缺Graph/Runtime时显示受阻并可跳过，不用模拟预览冒充完成。
