## 4. 当前必须完成的 LAN 交互

- 无外网、无ADB、无开发者模式、无平台登录/云配对/云中继；可互通的同一LAN即可，Windows有线+Android无线可用。SSID相同不等于可达；AP隔离、权限、网卡选择、防火墙与组播受限均要解释。
- 推荐 mDNS/DNS-SD 与 Android NSD 做发现；被禁时可用二维码或手工本地IP定位，仍要同等身份校验与配对，不绕过网络隔离。广播只含最小设备信息，不泄露项目列表、目录、缩略图。
- 首次双端本地确认，设备身份、信任关系、项目和操作范围明确，可撤销。配对不等于全盘授权，撤销后不得继续读取。二维码/日志不能携带长期密钥。
- 传输完整项目、本地资源库选定资源及依赖；接收为可离线独立编辑的完整副本。PC发手机固定版本试玩，手机改动可回到PC继续对话/工作流编辑。
- 各设备各目标项目单一DocumentCore/存储所有者串行提交；两端可独立编辑后合并，不指定PC永远为主。稳定项目/对象/资产ID、共同祖先快照、分支与内容哈希参与比较；两端独立revision和系统时间不能直接排序判胜。
- 差量与缺块传输、固定快照、分块/整包校验、临时区、依赖完整与原子领域提交。断网/锁屏/崩溃/空间不足/损坏时旧版保留，恢复须核输入快照，源变化不能拼接旧任务。禁止复制活跃SQLite/WAL/锁文件。
- 同字段、删除对编辑、图拓扑/引用、二进制资源冲突可审阅保留两侧，不以最后写入胜出。可选自动同步要显式开启；实时多人同编不在当前要求。
- WSS/TLS控制+HTTPS分块数据是交给架构的协议建议，确切线协议未在产品冻结；不得用裸UDP传大文件或未认证明文替代权限/校验要求。接口联网游戏所需其他协议沿原网络规格，不能与LAN传输混为一套无边界API。
- 工程、资源、元数据、缩略图、报告、路径和编辑历史不自动交云模型/MCP/遥测；云AI不能成为迁移/同步必需。模型/API/MCP凭据、配对密钥、登录态、签名私钥不随项目同步。无公网/cellular/STUN/TURN/UPnP后门回落。
- 中/英/日/韩，十二状态、诊断和恢复，新手默认不输IP。对端离线时保留本地创作；只关外网但LAN还在时同步继续。系统权限/生命周期由宿主适配，不要求关闭安全机制。

以上均为产品义务，不是本轮运行证据。AC-065—072逐项追溯；性能容量及操作系统版本阈值由架构提出，产品不伪造测量。

## 6. 输出、许可与 Cocos 边界

四个游戏成品目标保持 H5、WebView+C++编译WASM APK、微信小游戏、抖音小游戏。未来外部可编辑工程属于工具间交换产物；不能因此扩大 GameGen 自身发行平台，或把外部工具构建结果算成我们已支持的新发行目标。

GameGen自研引擎；Cocos仅参考。独立读取/序列化Cocos工程格式不等于集成Cocos引擎。GameGen本体及自身四目标不携带其源码、运行时、SDK、官方适配器、导出模板或工具链。未来可编辑Cocos工程在目标编辑器继续编辑/构建所需环境由用户另行安装，明确标示该副本的外部依赖，不包装成GameGen本体必需依赖。

如果某 Writer 需要复制第三方模板/代码/运行库或引入被禁依赖，应先报告冲突并在能力表排除，不擅自实施；不能用“格式兼容”宣称再分发权。当前没有批准例外。三引擎写出不自动授权复制原素材许可禁止转发的内容。

GPL是用户既有方向，独立游戏闭源商用是目标；现有架构 GPL-3.0-only+Runtime/Export Exception 为提案，不是已生效的许可承诺。自有例外只能涉及有权授权的代码，第三方义务另列；正式文本与权利链审阅待真实负责人处理。GameGen必需SDK/构建链不强制商业收费、版税或企业订阅。可选模型服务的计费沿原需求，不冒充引擎必需许可费。
