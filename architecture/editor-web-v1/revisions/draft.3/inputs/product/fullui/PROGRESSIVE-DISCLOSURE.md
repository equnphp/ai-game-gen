# 新手到高级的界面展开规则

版本full-ui-details-20261117-draft.1；2026-11-17。用户明确要求零经验新手快速上手，高级功能按需打开。下表是所有字段细化的展示层约束，不删除任何完整需求。

默认沿创建→改外观/行为→试玩→保存/导出。保留已有桌面/手机导航，不因高级工具多而给新手同时展开全部面板。手机工作流入口先给可理解的行为卡，高级画布可一键横屏并返回。

|---|---|---|---|---|
|创建与模板|玩法/视角/本地模式/模板或空白、名称|模块依赖、输入重绑、运行存档、格式与资源预算|已自定义/启用专业模块|新建→更多设置；不强制配模型/MCP|

|物理|固定/掉落/可推动/角色预设、尺寸/重力常用值|复合形状、矩阵/关节/CCD/查询过滤/阻尼|超出预设显示自定义、穿透风险|碰撞体编辑/高级参数，不删预设之外字段|
|粒子/动画/骨骼|选预设/角色/动作、播放、换皮/尺寸速度常用值|曲线、子发射器、顶点权重/IK、混合中断/事件|高级效果/预算/缺资源提示|高级模式独立工具区，关闭保留参数|

|地图|画地面/放物体/可走区/事件/试玩|通行面/投影参数/遮挡部件/占地/动态连接|当前层/面与高级已用，错误可直接定位|地图→所选对象/图层→高级；横屏不清草稿|
|关卡|选地图/出生点、一个目标、胜败/重试|复合目标/评分、检查点持久项、战役条件图|已用多目标/自定义奖励|关卡详情→更多规则|

|工作流|当…如果…那么卡、行为预设、定位结果|类型端口、变量/集合、并行/循环、子流程/状态机、调试|高级图已自定义/错误定位|高级图与简易卡同源，回简易不抹隐藏分支|
|对话与扩展|描述需求、少量澄清、变化预览、试玩|本轮版本/工具参数、模型高级、MCP/Skill|真实模型来源/当前任务/需授权或待处理|默认助手可用按实际能力；设置不成为首次必填|

|导出|四目标选择、身份/图标、预检定位、生成产物|签名/域名/分包/能力替代/工具组件版本|导出快照/缺组件/未验证运行|每目标独立设置，不能把专业字段隐藏后缺失|
|历史与恢复|最近完整保存、查看变化/恢复副本|锁定点/迁移/来源三方/只读未知字段|当前未保存/只读/待恢复|恢复不覆盖原件；危险清理单独范围确认|

- 字段advanced=false只说明在该已打开的操作面内可见，不代表这个专业操作面首次首页就全部展开。整面novice标签、上表和具体任务共同决定默认展示。
- 模板/项目/继承默认可预填，required表示提交合法性，不表示新手必须手工输入所有技术字段。
- 高级区错误必须在外层显示可定位提示，点击展开到具体字段；不得因收起而无声阻断。
- 恢复当前字段、恢复预设、恢复整个模板是不同动作；范围影响先说明，保留无关自定义。
- 用户可记住工作区展开偏好；这只影响设备UI布局，不改游戏数据/规则。
