## 架构需承接的产品合同

1. 课程资源随本地编辑器组件提供；内置示例资源可离线使用并保留许可。缺组件不触发自动下载或云调用。
2. 稳定guide/step ID和版本映射、可恢复的本机偏好写入；工程文档和学习进度严格分开。写失败不得显示已记住；进度不能授权真实业务动作。
3. 既有正常动作/任务事件是完成依据；引导只观察/引路，不直写工程、不执行隐藏脚本，不因结束教程取消/重放真实任务。
4. “新建练习”复用正常创建命令身份，重复开始不重复创建。当前项目草稿保护、保存durable、隔离试玩、localOnly沿既有合同。
5. 提示锚点用稳定语义ID，随布局重定位；目标不可见/对象失效/模态权限优先时可暂停/回落步骤卡。不得依赖中文文字或固定像素坐标识别按钮。
6. 教程进度默认不经LAN/工程包/游戏导出传输，也无自动遥测。实际模型/MCP与签名/导出沿既有凭据、权限与费用边界。
