# 七语言的启动、存储、资源与交互设计

版本：editor-web-v1-draft.4。产品[LANGUAGE-SETTINGS.md](inputs/product/localization/LANGUAGE-SETTINGS.md)及[language-settings.json](inputs/product/localization/language-settings.json)是业务来源。本文件是待实现设计，全部实测not_run。

## 1. 唯一语言选择与启动顺序

|规范ID|面板固定本语言自称|
|---|---|
|en|English|
|zh-Hans|简体中文|
|zh-Hant|繁體中文|
|ja|日本語|
|ko|한국어|
|es|Español|
|fr|Français|

英文是首次默认，不是系统语言推导。选择器固定七项、带当前有效勾选和单独保存中/失败项，不用国旗、不提供本轮未要求的地区变体。首页、欢迎卡、工作区Settings → Language引用同一个状态/组件，跳过教学或未登录不隐藏入口。

启动先载入随包最小英文安全界面和本机设置；仅有效已存显式选择可替代英文。读取期间必要等待页英文，不先加载中文主页再闪换。缺配置、损坏、未知代码或读失败：有效语言为en，source=default，persistedLocale=null或实际可识别值，给出安全说明；这不产生“用户明确选英文”的写入。未知未来schema保留原件只读并说明升级，不把未来文件当空白重写。

系统、项目、LAN对端、账号和入口来源不参与选择优先级。卸载清数据后可回到首次状态；正常升级不删设置。未来多本地profile逐档隔离；当前OS用户/设备独立，未登录与登录切换沿用当前profile，不加云同步。

旧资源/已有显式设置的地区代码只在受控入口映射到七个规范ID，[locale-policy.json](contracts/locale-policy.json)给明确表；例如zh-CN→zh-Hans、zh-TW→zh-Hant。映射不是按系统语言选中文；裸zh等未声明歧义值不猜。UI/wire只使用七个规范ID。已知旧设置可在成功接收后迁移；仅有旧资源文件不证明用户曾选该语言，也不自动选用。

## 2. 同源模块

React LocaleProvider订阅真实localeState；LocaleCatalog持有随包消息资源，LocaleFormatter处理命名参数、完整句式、复数和显示格式；LanguagePicker只发送用户意图。LocalPreferencesActor由Rust宿主统一拥有语言设置，与课程actor协作但不让教学进度CAS决定语言成败。

表现层不因locale改变重建ProjectSession、Core、Agent或PreviewHost。组件key使用SUR/对象/字段ID，不使用翻译字符串或语言码重挂整个工作区。当前编辑输入在组合输入法结束前保留原文本和caret；本地化可访问名和根lang属性更新，业务草稿不能被格式化覆盖。引擎文字工具和图视口使用正常标签刷新，不清选择或重置相机。

C++不接收编辑器locale作为项目写入，Kotlin/Swift仅提供目录/持久化/无障碍必要端口，Windows/Android共享同一编排和目录策略。系统权限对话框等OS拥有文本服从OS能力，编辑器外围说明用已选语言，不声称可重写系统UI。

## 3. 持久化与异常

独立文件editor-profile/editor-locale-v1.json包含schemaVersion=1、稳定localeStoreId、locale、该store实例内单调localeRevision(u64字符串)、最后提交commandId/ticket以及必要完整性元数据。文件最大8KiB；不含Key、消息、路径、项目/账号内容、课程进度或系统语言。ticket只在当前服务epoch内解释，最后提交同时保存原服务实例；跨服务以store身份/revision/commandId核对。损坏文件显式修复换store身份，不能让重建版本伪装旧序列。

单OS用户/profile由同一个LocalPreferencesActor写，生产多进程需宿主独占锁/转发，不允许两个写者各覆盖文件。Windows/Android只将原子文件端口分开。写入采用同目录临时文件、flush/sync、已验证结构、提交闸门、同卷原子替换及一个有界上一有效副本；以平台实际能力接收，不能凭流程文字保证断电RPO。替换后的持久性结果不明进入reconciling，核对目标文件，不发“保存成功”。

普通明确失败保持上一有效持久化记录和已选语言；不把候选设effective。损坏原件隔离保存，显式选择可在保留恢复证据后创建schema1文件；未知未来schema不强写。读取/迁移失败的英文安全回退不清理原件。课程重看、引导记录reset、工作区布局恢复不触碰此文件。未来“恢复全部编辑器设置”须列明语言范围，可通过正常显式选择en重置；不能用课程reset暗带重置。

内存accepted、磁盘committed、界面effective分别表达。只有确认实际本机提交的选择才应用；localeState与引导profileRevision/persistedRevision是不同命名空间。语言写失败也不影响Core项目保存状态，Core成功不证明语言已记住。

## 4. 快速选择、重连与最后意图

每个可信UI连接从describe取得selectionChannelId，通道绑定workspace/WebView实例；客户端每次真实新选择递增selectionSeq。宿主拒绝旧通道和非递增旧选择，不能让网络乱序的旧点击盖过新点击。commandId对同一意图幂等，传输callId不是意图ID。

LocalPreferencesActor为接受的合法意图分配单调ticket。每个profile最多1个写入工作和1个最新待处理选择；待处理队列覆盖为最新意图，已被替代的意图标superseded，不生成无界队列。文件提交前在actor最终闸门核对ticket；已被新意图替代且未提交的暂存文件直接丢弃。提交闸门与原子替换的线性化区间内不能交错接受更新ticket。

若A已实际提交才接受B，A是此前真实有效设置；B保存期间面板显示待保存B，不以迟到A响应清除它。A响应不能盖回B成功后的状态。B明确失败时保留并展示已核实的上一有效设置，可能是已提交的A，清楚标B失败/可重试；不能回报B保存成功。各窗口按服务ticket/localeRevision应用权威事件，发起窗口另用本地selectionSeq过滤迟到响应，不靠机器时钟比较物理点击。

重复点同一语言在无其他意图时为unchanged，无额外写入。若当前显示A但B在途，又主动选A，这是新的最新意图，必须阻止未提交B，或在B已提交后正常写回A；不能只按画面文字误判无操作。

断线/超时不是失败。重连先snapshot/核对原commandId、待处理ticket和已存revision；结果未知期间不自动换ID重放。最近128个命令回执/通道序列是内存有界辅助；进程重启换serviceInstanceId和通道，读取文件最后提交身份，未提交选择不能宣称记住。用户主动重试才建立新意图，不重放任何项目/模型业务请求。

## 5. 离线资源、缺译与格式

七语目录和基础帮助/引导随编辑器安装；切换不联网下载、调用模型或扣费。本版只定义目录，未交付真实全量翻译。资源使用稳定messageKey/命名参数/完整句式，按locale分文件并带资源schema/版本、键清单、参数类型和包摘要。资源是数据，禁止eval、任意HTML或路径/脚本加载；用户文本安全插值，链接/富文本采用受限结构。

简体与繁体各自维护与审阅，不通过运行时字形替换假称繁体完成。数值、日期、复数可复用现有平台标准格式能力，按统一LocaleFormatter封装；具体WebView/字体/格式数据版本在实际环境接收时锁定，输出差异未实测。时间显示默认宿主本地时区，工具显式固定时区时标明。Core计算、JSON数值/枚举、时间戳存储、单位机器值不本地化。

逐键查询先所选语言，再英文，再最小英文安全说明；不显示裸键或空按钮，不以简体代替繁体。缺键不把已选locale改成en，不谎报资源完整；本机脱敏缺译记录用于补齐，默认不上传。每个LANG-AC与其适用关键流程七语缺译目标0；英文安全回退只是可恢复机制，不是七语验收通过。

只刷新编辑器内置文字、帮助、通知、控件/可访问标签、内置节点名称与说明。用户工程/对象/自定义变量、既有聊天/模型历史、API原文、协议标识及第三方原始错误保持原文；第三方错误外围解释本地化、详情脱敏。用户输入数值按字段明确解析策略校验，不拿本地化显示串改写已有机器数据。

新发送的Agent轮次冻结responseLanguage：用户本轮明确回复语言优先，否则取发送时effectiveLocale。服务间只传必要语言标识和本来已授权的请求；localOnly继续生效。中途切换不翻译历史、不改已发请求/重试原字节、不重开模型；下一新轮次才用新默认。实际回复语言依赖供应商能力，不承诺模型每次正确。

游戏语言由项目本地化系统独立管理；编辑器切换不改游戏默认语言或成品语言列表。R/F说明也本地化但不会因此变成可执行能力。

## 6. 适配与可观察性

213操作面、88状态/28组合、六个引导视图和所有高级/失败/空/通知状态都列入适用文字范围。法/西长文可换行；中日韩/简繁字体覆盖与合法离线字体资源由UI/资产接收固定，不凭“系统有字体”假设完整。保持窄窗/大字、Android横竖屏/键盘/安全区、读屏与减少动效要求，语言/跳过/主要动作可达。

语义定位使用role、SUR/field/action/step和业务对象ID；可访问名称随语言变化，自动化按固定语言环境或稳定语义身份定位，不能硬绑中文或屏幕像素。真实UX snapshot可观察有效/已存/待存语言和提交状态，项目查询观察切换前后业务事实；不提供注入“已保存”的测试端点。mock标明身份，不能证明离线落盘或七语资源正确。

后续独立quality编制跨语言、快速连选、存储失败、恢复、隐私、设备/可访问性等系统文案；实际运行另需用户会话授权。当前没有翻译正确性、字体、排版、设备或运行证据。
