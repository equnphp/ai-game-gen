# 编辑器七语言与持久化语言设置

版本：localization-20261117-draft.1；2026-11-17。来源：用户连续明确“多语言、默认英文、保存选择”，并指定中/英/日/韩/西班牙/法文，最后增加繁体中文。本文对原完整UI需求包及新手引导包的“四语”范围作增量修订，今后相关设计与实现统一按七语言执行；冻结历史稿仍保留原记录，不视为已完成七语翻译。

## 1. 支持范围与默认值

|稳定语言标识|选择器显示名称|含义|
|---|---|---|
|en|English|英文，首次默认|
|zh-Hans|简体中文|简体中文|
|zh-Hant|繁體中文|繁体中文，独立选项|
|ja|日本語|日文|
|ko|한국어|韩文|
|es|Español|西班牙文|
|fr|Français|法文|

语言名称固定用本语言自称，不用国旗代替语言，不以当前界面语言隐藏其他选项。这里的标识用于需求追踪；若既有资源有en-US/zh-CN等地区代码，架构在资源入口明确映射，不能重复显示同一种语言或把简繁合并。未增加地区变体切换器；七语均为从左向右的本轮范围。

**首启无有效用户选择时使用英文，不按系统语言自动改成其他语言。** 读取到有效已保存选择时，优先使用该选择。选择缺失/损坏/未知代码时回退英文并保留可达的语言入口；正常升级保留已有有效选择。历史项目语言、系统语言、登录状态、打开来源及LAN对端语言均不能覆盖用户明确选择。

## 2. 语言设置界面与操作

- 项目首页/首次欢迎卡提供可见的地球图标+“Language”入口，未登录和已跳过新手引导也能切换；工作区设置中固定入口为 Settings → Language。切换后入口标题随当前语言本地化，图标保留。
- 同一语言选择面板用于首页、引导和设置，不创建互相独立的语言配置。列表给当前选中标记、七个本语言名称；英文的默认说明与当前已选状态区分。
- 用户选择后自动保存并立即应用，不要求重启或再次点击保存。保存成功后短提示“Language saved”，用新选择的语言显示。
- 写入失败时保留此前有效设置和已选状态，显示可重试/关闭的明确错误；不假称“下次会记住”。选择器内可显示待保存项，但当前有效语言与待保存选择必须区分。
- 重复点同一语言无副作用；快速连选时以最后一次有效用户选择为准，旧保存结果不能盖回新选择。取消/关闭面板不丢项目草稿。
- 切换时保持当前页、选择对象、工作流视口、输入草稿、撤销历史、任务身份与新手步骤；不重开教程、不重复发送AI请求、不重复保存项目或启动构建。

语言设置属于**本机、当前编辑器用户配置**，与工程分离；更换项目、关闭进程、重启设备及软件升级后保留。未登录使用本机配置；登录/退出账号不突然重置或同步覆盖本机选择；若未来有独立本地编辑器配置档，各档各自保存。Windows与Android各自保存自己的选择，macOS/Linux同样遵守本地持久化规则，不依赖联网。

不自动把该偏好写进项目、局域网同步包、发布游戏、云端账户或遥测。恢复工作区布局不重置语言；恢复整个编辑器设置时若包含语言，须在重置范围中写清楚，重置后为英文。卸载/清除应用全部数据可使选择丢失，重新安装无配置时仍英文。

## 3. 覆盖的界面和内容边界

七语言适用于所有编辑器内置UI：项目管理、对话控件/系统状态、工作流节点显示名及说明、场景/地图/关卡/物理/粒子/动画/骨骼/音频/数值/RPG/SLG工具、模型/MCP/Skill/API设置、LAN/三引擎导入报告、四目标导出/恢复/错误/权限提示、帮助与新手引导。包括隐藏高级功能、空态、无结果、错误、后台通知、确认弹窗和无障碍标签，不能只翻译首页。

内置本地说明和七语基础字符串随编辑器离线提供；不因切换语言联网下载、调用模型或扣积分。后续R/F能力的说明也跟随选择，但翻译完成不能把未交付能力显示为可执行。

- 简体与繁体是独立资源与文案审阅范围，不仅改选项名称或对全界面做机械字形替换；繁体常用词、换行、标点需相应处理。
- 已有用户聊天内容、模型历史输出、工程名、对象名、资源文件名、用户自定义节点/变量、API文档及第三方协议标识保持原文；切换UI语言不改游戏数据或重写聊天记录。
- 对话助手的新回复在用户未指定其他回复语言时，以当前界面语言作为默认回复语言；用户本轮明确指定的回复语言优先。该偏好不自动翻译/发送本地工程内容，不改变localOnly规则，模型实际语言服从能力与请求，不能保证每次输出完全正确。
- 工作流节点稳定ID/端口类型/枚举值、导入映射和项目序列化值不因显示语言变化而变更。显示文案与机器身份分开，不能用翻译文字做查找主键或工具锚点。
- 游戏内语言继续由项目本地化工具管理；本次修改的是编辑器语言设置，不自动更改已有游戏文案、游戏默认语言或成品语言列表。新手引导跟随编辑器且不重置进度。
- 第三方原始错误保留脱敏原文，外围解释按UI语言；不假造第三方原文翻译。内置提示使用稳定错误码映射，未知项给可理解的通用说明与展开详情。

缺失某条内置翻译时逐键回退英文，不能显示裸资源键、空按钮或以简体悄悄冒充繁体。必需关键流程出现缺译需登记补齐；回退机制不等于七语验收完成。不因一条缺译重置用户已选语言。

## 4. 状态与异常恢复

|状态|内容/动作|恢复边界|
|---|---|---|
|首次/偏好为空|英文界面+七语选择入口|没有强制语言向导，可直接开始或跳过新手引导|
|正常|当前语言勾选，其他六种可选|选择前后不改变项目内容|
|初始读取/保存中|启动先读本机设置；必要等待页用英文；选择面板显示保存中|不先全页错误闪成中文；读写绑定本机设置请求|
|无可用资源|英文安全回退和语言入口|不联网获取、不丢项目；缺组件给原因|
|无搜索结果|默认七项直接列表无需搜索；若复用组件带搜索则保留输入和清除|不自动增加不支持的语言|
|未登录/离线|正常切换和持久化均可用|不要求账户或公网|
|权限/存储不足|写失败、原有效语言、重试/关闭|不将失败展示成已保存|
|错误/超时|读取失败回退英文；写入结果未知先核对本机已存值|不无限重试，不回放业务请求|
|重复/快速切换|最后有效选择与保存状态明确|旧响应不覆盖新选择|
|中断/恢复|重新读取已持久化选择|保留项目和任务；若保存未完成只认实际存储结果|
|成功|新语言立即生效，保存成功提示|下一次启动沿用，无需重启|
|语言包版本变化|保留可识别已选代码，缺键英文回退|不自动跳回系统语言，不重复欢迎|

## 5. 排版、本地化与可访问性

文本使用统一语言资源键，支持参数占位、数量变化与完整句式，不拼接中文语序；用户输入按文本安全显示。翻译资源的参数名、数值单位与项目机器值不能擅改。日期/数量显示按选定语言的格式策略处理，文件名、序列化、计算和协议数据保持统一可交换格式；区域细节由架构/组件规范统一，UI不各写一套。

西班牙文/法文长标签可换行或调整布局；日/韩/简繁字体回退、字符覆盖与输入法兼容均需覆盖。手机大字号、横竖屏、键盘和安全区下，语言选择、跳过引导、保存状态和关键动作可达。读屏名称/界面语言标记随选择更新，切换不抢输入焦点；七语本语言名称无需用户先懂英文才能找到。
