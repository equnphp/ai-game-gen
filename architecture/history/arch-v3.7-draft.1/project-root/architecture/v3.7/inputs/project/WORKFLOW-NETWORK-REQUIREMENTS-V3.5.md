# 对话、工作流、联网与积分产品需求补充 V3.5
日期：2026-11-14
文档性质：产品需求与验收规则。以下用“应/必须”定义成品行为，不表示现有原型已经具备能力。实现进度不属于本文件的需求正文。
审阅输入：PRODUCT.md、WORKFLOW-ARCHITECTURE.md、ARCHITECTURE-V3.3.md、evidence/v3.3/reviews/opensource-network-study.md。

## 1. 统一产品约束
1. 成品包含多事件、子流程、受控循环、异步、状态机、调试与版本管理。
2. 新手不应先填写协议/鉴权/同步算法。用户先选择单机、好友联机、房间对战、持续世界等目的，专业配置在同一项目内按需展开。
3. “发接口文档给AI”必须定义导入、定位、缺项、人工覆盖和升级合并；不能只有上传框和生成按钮。
4. “支持WSS/Socket”必须同时定义连接、消息、鉴权、背压、重连、失败及各导出目标的能力限制，不能只增加协议下拉框。
5. “RPG网游”必须包含权威玩法、角色持久化、可见性、地图迁移和经济一致性；创建模板不能代替这些规则。
6. “生成后扣积分”必须覆盖停止、断线、超时、重复请求、生成成功但入库失败、部分成功和退款对账。
7. 对话/工作流、简易/高级不是两份逻辑；统一版本、引用和事务必须成为用户可感知的保留与恢复规则。

## 2. 对话工作台与本机 OpenCode
### 2.1 用户能力与操作
- 每个项目有多个命名会话；支持新建、改名、搜索、归档、恢复、导出记录、从指定消息分支。归档不删除项目或已应用修改。
- 会话支持“讨论方案”和“执行修改”。讨论只读取授权项目上下文并形成计划；执行可生成结构化配置、资源任务及工作流变更。模式切换保留输入、附件和上下文。
- 输入可附加地图、关卡、对象、节点、工作流、数据表、接口、错误记录或选中文件；附件显示名称、版本、发送范围和移除入口。
- 输出分为解释、待回答问题、步骤计划、工具活动、资源任务、变更卡和运行结果。工具活动默认折叠，失败时给出直观原因和定位入口。
- 支持停止、继续、重试、修改上一条指令、引用原消息。重试作为同一请求的恢复或新任务必须在界面明确区分，不能重复提交图修改或重复扣费。
- 生成时用户仍能查看和手工编辑项目；切换页面/语言/横竖屏不能改变任务绑定的项目、地图、图和版本。
- 用户可在后台任务中心查看进度、取消、重试和结果；应用重启后恢复会话、任务状态及已提交变更记录。

### 2.2 本机与模型规则
- Android和PC编辑器均在本机运行OpenCode内核及其API。Android不得把“连接电脑/云端Agent”当作本机内核的替代。
- 断网时可以打开本机内核、会话和项目，进行人工编辑、工作流校验、试玩及具备本地依赖的导出。需要云模型的新对话生成显示“需要联网”，保留草稿；用户主动选择加入联网队列后才可在恢复网络时继续。
- 对话模型优先提供官方免费通道；界面显示当前通道、模型、剩余额度或“由供应方动态管理”、可用状态。免费通道不可用时给出原因和其他选择，不能宣称永久免费或无限额。
- 付费模型统一通过本产品服务端网关；用户明确选择允许付费及预算后使用。免费额度耗尽不得静默切换付费。允许用户设置“仅免费”“每次确认”“在本次/本项目预算内自动续用”。
- 运行内核、本地文件访问授权、模型数据发送范围及积分授权分别表达；一项授权不能隐含其余授权。
- 本地内核仅能通过受控领域工具修改项目。用户项目不得出现任意脚本/命令节点，也不得通过AI工具把可执行代码藏进文本参数。

### 2.3 问题澄清与默认
- 只追问会改变玩法、资产、接口业务或收费的关键缺项；可逆细节使用模板默认，并在变更卡注明。
- 例如爆炸音效缺失时，显示“选本地文件 / 使用免费内置音效 / 本机生成 / 云端生成（积分报价）”；支持试听、替换及稍后设置。
- 多个问题在一张卡中处理，允许选择“按推荐继续”。用户回答前，独立的免费步骤可继续；依赖答案的步骤暂停，不能用猜测替代必要的权限/金额/业务答案。
- 用户手工修改的内容优先保留。需求冲突时明确受影响对象、原规则和拟替换规则，提供保留原规则、仅应用无冲突部分或重新生成。

### 2.4 验收
切换模式和重开应用不丢草稿；停止后没有后续自动写入；一次任务只产生一笔已提交事务及对应结算；Android离线仍可调用本机内核API；免费转付费必须满足用户选择的预算规则。

## 3. 同一项目与变更管理
### 3.1 统一编辑规则
- 对话、场景拖放、简易卡片、专业参数和工作流编辑共同修改同一对象和稳定ID。
- 变更卡以用户语义显示新增/删除对象、地图/数值变化、条件/动作变化、资源引用、接口与服务端规则变化；允许定位、对照和逐组应用。
- 应用前校验类型、引用、执行域、目标平台和预算。校验失败时保留草案并定位问题；不得部分写入一个事务。
- 每次提交记录来源、请求、时间、基线、涉及对象及简要原因。支持撤销/重做、命名版本、分支、比较、恢复副本。
- AI基于旧版本生成时，先比较双方变更。不相交内容可重基；同字段/引用依赖冲突必须显示，不得覆盖用户的新修改。
- “应用无冲突部分”先计算依赖闭包，无法独立成立的对象/连线归入冲突组；不能留下失效引用。
- 简易预设被高级修改后显示“已自定义”。简易可编辑字段继续绑定原数据；收起高级、切换语言或再次对话不得删除额外分支。
- 共享资源修改显示受影响场景；提供修改共享定义、仅当前实例覆盖或复制为独立资源。删除被引用资源先提供替换、解除引用或取消。
- 试玩运行状态与编辑文档隔离。停止试玩默认还原运行中的位置、生命、金币和临时对象；用户明确选取允许的可回写字段后才可形成编辑变更。

### 3.2 异常与恢复
保存失败保留内存和恢复日志并提示路径/容量原因；损坏文件保留原文件及备份，不自动覆盖；旧格式迁移先产生副本及迁移报告；新版本不认识的内容保留并只读显示，不能保存时删掉未知字段。

### 3.3 验收
手工新增条件后再让AI改音效只修改相关字段；撤销AI事务完整恢复；两个会话修改同一对象触发冲突；共享资源删除无悬空引用；试玩结束不把运行金币写回项目。

## 4. 完整工作流能力与操作
### 4.1 工作流种类
共用节点目录、类型、稳定引用、版本和事务，按语义提供：
- 事件/动作图：输入、场景生命周期、碰撞/区域、交互、关卡、任务及消息事件。
- 条件/数值子图：类型化运算、公式、曲线、表查询、集合筛选和明确对象挑选范围。
- 状态机/行为树：进入/更新/退出、转换优先级、中断条件、默认状态、目标选择。
- 动画状态与混合图：动作条件、过渡、动作事件、参数和角色挂点引用。
- API/异步图：请求、消息、数据库/事务、定时任务、取消、超时和错误分支。
“不同图”保持语义明确，不能在纯公式图中直接发网络请求或发奖励。

### 4.2 画布操作
- 节点搜索可按“我想做什么”、分类、端口类型、当前对象及执行域过滤；显示推荐节点、示例和所需参数。
- 支持添加、拖放、吸附、对齐、框选、多选、连线、删线、在线插入节点、复制/粘贴、分组、注释、折叠子流程、撤销/重做和定位引用。
- 连接时显示合法端口及不合法原因；允许点选端口后选择目标，手机不依赖精细拖拽。
- 属性显示人类可读名称、说明、单位、默认值、合法范围、引用选择、恢复默认及字段校验。变量/节点显示名可翻译，稳定标识不随语言改变。
- 手机竖屏提供流程列表/卡片和属性抽屉；一键横屏后画布与属性并排；返回保留选择、缩放、平移、输入、连线草稿及撤销历史。
- 工作流能以“当……如果……就……”自然语言摘要展示；点摘要定位节点，修改摘要仍形成可审查图补丁。

### 4.3 执行规则
- 多事件入口各有明确触发条件和事件参数。同一事件内的动作顺序通过显式执行线表达；多个事件的共享写入按规定调度顺序串行提交。
- 数据线只传值或引用，不隐含触发执行。列表操作明确“当前对象/全部已选对象/全局集合”，避免同名对象误作用。
- 条件分支有明确真/假出口；分支汇合不重复执行。并行必须使用并行节点并声明全部完成/任一完成及失败策略。
- 循环只能通过有界循环、遍历集合、计时器或状态机表达；禁止普通连线形成无界回环。每次调用有执行预算，超预算走错误出口并保留调试记录。
- 等待、网络、动画、资源任务按节点类型提供自然完成/成功、失败、超时、停止/打断及取消等对应出口，保留终态原因，不能统一当作自然完成；等待不阻塞其他事件。销毁对象/退出地图时按节点生命周期取消或转移任务。
- 子流程声明输入/输出、执行域、副作用及错误；版本更新先显示影响，不自动改坏所有调用者。递归默认禁止，启用时必须有可检查深度上限。
- 空值、缺失引用、除零、类型溢出、无目标对象都有明确错误/默认策略，不能默默使用0或第一个对象。
- 随机行为支持指定种子和运行种子记录；可信时间、奖励、付费和持久化等节点按服务端执行域限制。
- 新增引擎节点属于平台版本化能力目录；AI只能组合已有节点。缺少节点时可以提出功能建议，不能自行塞入代码绕过目录。

### 4.4 调试与验收
支持运行/暂停/单步/断点、节点高亮、端口值、调用栈、事件时间线、日志筛选、错误定位、模拟输入与重播；真实请求、模拟响应和历史回放必须有明确标签。多入口、并行取消、循环超限、地图切换取消、服务器权限越界都要有独立验收用例。

## 5. API文档导入、AI生成与人工配置
### 5.1 输入与生成流程
支持OpenAPI JSON/YAML、AsyncAPI、proto、Markdown、PDF、文本粘贴及示例请求/响应。图片/扫描PDF通过文字识别后显示识别置信度和原文对照。
操作为“选择来源 → 识别格式与版本 → 显示将发送AI的范围 → 解析 → 汇总缺项/冲突 → AI映射建议 → 人工调整 → 差异预览 → 应用为契约与工作流”。
只做确定性解析可在本地完成，不因解析本地结构化文档强制调用模型或收费。文件/页数/引用深度上限按产品配置显示；超限必须定位并提供拆分，不能静默截断。

### 5.2 契约完整字段
- 服务与环境：名称、稳定ID、版本、用途、开发/测试/生产地址、地域、证书/凭据引用。
- HTTP操作：方法、路径、query/path/header/cookie、body类型、请求/响应schema、成功码、业务错误码、分页、幂等键和限流。
- 消息操作：通道/topic、事件名、方向、payload、关联ID、序号、确认、重放/过期规则、会话与订阅。
- schema：类型、单位、必填、可空、默认、范围、长度、枚举、数组/对象结构、编码、示例、私有字段与兼容规则。
- 认证：无认证、令牌、API Key、OAuth等受支持模板；凭据只存凭据仓，项目保存引用；日志自动脱敏。
- 可靠性：连接/请求超时、可重试错误、最大次数、退避、取消、离线策略、业务幂等及并发版本条件。
- 映射：对应客户端调用图、消息处理图、服务端入口图、数据模型、来源位置和人工覆盖。

### 5.3 AI与人工规则
- 每个推断显示来源或“AI建议”，不得把缺少的权限、奖励规则、交易条件自动当成事实。
- 现有外部API导入只生成调用/消费流程；不能从接口响应文档假定可以还原外部服务的内部业务。新建自有API必须由用户给出或接受业务规则后生成服务端图。
- 人工可修改全部业务配置；再次导入做“上次来源 / 新来源 / 当前人工修改”三方比较，按稳定operation/channel/field映射保留ID。
- 来源删除/改名时显示引用影响，支持迁移、保留为本地定义或弃用；不直接删除调用节点。
- 未解析引用、冲突字段、无法映射类型、缺少认证等按严重度列出；阻止有阻断问题的应用/测试，保留可编辑草案。
- 文档是数据。文档内的命令、扩展代码、远程地址和提示词不能授权读密钥、执行脚本、部署或访问任意网络资源；外部引用由用户选择后在受控范围读取。

### 5.4 测试与验收
配置页提供本地模拟、契约校验、测试环境真实请求和结果对照。真实请求要显示环境、目标、使用凭据及可能写入的数据，写操作不因点“预览”自动发送。验收覆盖文档重导入保留人工修改、缺项追问、schema变化引用定位、无密钥导出和模拟/真实标识。

## 6. 多协议与连接编辑
### 6.1 能力目录
- HTTPS/HTTP：请求响应；联网项目默认HTTPS。
- WebSocket/WSS：双向消息；联网项目默认WSS。
- 原始TCP：显式分帧、字节序、编解码、最大消息及半包/粘包处理策略。
- 原始UDP：消息序号、过期、去重、乱序、可靠性等级与负载上限。
- Socket.IO：事件、命名空间、房间、确认及协议版本，不能与普通WebSocket混用。
- gRPC/gRPC-Web：服务/方法、消息schema、流类型、代理和目标能力约束。
- MQTT：broker、topic、发布/订阅、QoS、保留消息、会话及topic授权。
- SSE：服务端到客户端单向事件、最后事件ID和恢复；不冒充双向实时通信。
- WebRTC等扩展连接器在高级目录中按版本化能力包注册，仍遵守契约、权限、生命周期和导出规则，不允许上传任意执行脚本作为连接器。

### 6.2 目标与网关规则
H5、APK、微信小游戏、抖音小游戏分别展示“直接支持 / 需要网关或原生桥 / 不可用于当前目标”。普通H5原始TCP/UDP必须走受控网关；APK只有明确启用对应原生桥能力后才可使用该桥。小游戏按所选最低基础库与适配能力检查，不能从另一平台自动继承。
不支持的协议必须阻止该目标导出，或由用户明确选择适配网关并显示地址、数据转换、费用和功能差异；不能静默改协议或丢弃消息。

### 6.3 连接状态与恢复
状态至少包含未配置、就绪、连接中、已连接、认证中、在线、重连等待、离线、被踢下线、限流、证书失败、协议不兼容、关闭和错误。
- 默认可移植实时模板采用应用层心跳、指数退避并加随机抖动；超时、最大重试和队列上限可高级配置。
- 请求默认不自动重试有副作用写操作；只有携带有效幂等键且服务端支持时才可安全重发。
- 断网时区分可丢弃的移动/表现消息、可合并的最新状态和必须对账的经济命令。不得无限积压，也不得重连后把旧移动/攻击全部补发。
- 背景/锁屏切换按目标生命周期暂停或降低发送，恢复后先验证会话与权威快照。
- 高级诊断显示延迟、抖动、丢包/重连次数、发送/接收量、队列、最后错误和脱敏消息；普通用户只看到连接状态与恢复操作。

## 7. 联网RPG、SLG与持续世界
### 7.1 创建与模板
创建前选择单机、好友联机、房间对战、异步回合或持续世界，可与RPG/SLG/经营等类型组合。模板提供账号/角色、连接、地图、同步字段及完整基础图；高级可调整人数上限、房间/区域、可见性和同步策略。
模板必须明确数据是否持久化、玩家掉线如何处理、谁拥有最终规则、是否可离线玩和是否需要独立服务部署。

### 7.2 权威与同步
- 客户端发送移动、技能、交互、建造、交易等意图；服务器校验身份、对象归属、距离、冷却、资源、地图和版本，计算伤害、掉落、胜负与资产。
- 允许视觉预测与插值；权威纠正后平滑恢复并记录差异，客户端不能直接覆盖服务端金币/装备/经验。
- 每个同步字段声明所有者、可写域、接收范围、频率/触发方式及私密性。服务端不向无权限客户端发送隐藏敌人、私有背包和其他敏感字段。
- AOI按地图位置、通行面/区域、队伍、阵营和玩法可见规则筛选；战争迷雾不是只在客户端把已收到的数据涂黑。
- 支持房间匹配/创建/加入/退出、邀请、准备、开始、结算、解散与重连；主持人离开规则在模板中明确。
- 持续世界支持角色选择、出生、地图实例、公共/私有区域、跨地图迁移、实例容量与排队；同一角色同时只有一个有效权威归属。
- 跨区转移使用可对账状态：发起、冻结可迁移状态、目标接收、确认、完成/回滚。重复转移、途中掉线、目标满员不能复制角色或丢失物品。

### 7.3 持久化与经济
- 账号、角色、背包、装备、技能、任务、邮件、好友/队伍/公会、排行榜、交易和世界进度按模块可选。
- 角色数据与任务定义分开；配置更新有版本兼容和迁移规则，不能把策划表修改当成清空玩家进度。
- 领奖、掉落归属、消耗、合成、购买、转账和交易使用唯一业务号、事务、并发版本及审计流水；重复请求得到同一结算结果。
- SLG建造、生产、研究、行军、驻扎、战斗与采集以服务端时间和队列为准。离线产出上限、取消返还、加速、占领和同时到达的结算顺序必须在规则中可配置。
- 重连先恢复会话与快照版本，再追赶可恢复事件；奖励/交易按业务号对账，不能按消息是否超时推定失败而再执行一次。
- 存档冲突提供权威版本、时间、摘要和选择规则；有交易资产的在线角色不允许用户任意把旧本地存档覆盖到服务器。

### 7.4 管理与发布
联网项目包含客户端包、接口/消息契约、服务端工作流、数据模型、环境配置、权限、迁移、监控与回滚包。测试/生产环境分离，生产变更有影响预览和版本绑定。
创作者可查看在线/房间/区域、错误、延迟、运行消耗、任务、经济审计和封禁/解封权限；敏感操作留记录。维护停服、公告、断线恢复、备份恢复、配置回滚及异常发奖冲正均有用户操作和权限。
大型世界的容量以服务规格和实际运行配额显示，满员时排队/拒绝/分区；不能只用“MMORPG”模板名隐含无限人数。

### 7.5 验收
覆盖两客户端同时操作同一资源、重复领奖、掉线重连、旧消息、会话替换、跨区失败、隐藏信息过滤、离线队列结算、回滚及恢复。通过条件是业务结果与规则一致，不能以“已连接WSS”代替。

## 8. 资源生成、积分和任务结算
### 8.1 任务与资产
图片生成、音效生成、导入文件和对话是独立可追踪任务。资源任务记录提示、参考、参数、模型/版本、来源、报价、产物、缩略图/试听、任务号及关联变更。
本机生成音效先显示本地模型所需空间、下载和设备运行选项；本地可用模型下载完成后允许断网生成。本机计算本身不扣云端积分；云端任务按报价结算。
图片/音效完成后进入资源收件箱，允许预览、重命名、标记、替换、应用到对象或保留。生成完成不自动覆盖当前资源；“重新生成”新建可比较版本。

### 8.2 积分规则
- 任务启动前显示免费/付费、估算范围、单次上限、计费单位及失败/停止规则。需要大额或超出既有授权时才请求新的积分授权。
- 统一过程为报价 → 冻结额度 → 执行 → 可用产物/用量确认 → 结算 → 释放余额。每个业务请求只对应一个结算键。
- 积分不足保留请求与参数，允许降低规格、换免费方案或补足后继续；不先消耗后提示余额不足。
- 对话按已告知的有效用量结算；用户停止时，只结算停止前已产生且计费规则允许的用量，显示明细且不超过授权上限。
- 云媒体任务失败、审核拒绝或没有交付可用产物时不收最终积分并释放冻结；已经产生的供应方成本不能直接作为用户欠款。
- 有效媒体已交付到资源收件箱即按报价结算，是否应用/是否喜欢不影响已发生的生成费用；重新生成前给新报价。
- 生成成功但入库失败，保留任务产物并免费重试入库；不能要求用户重新付费生成。部分成功按事先公示的单产物计费，退还失败部分。
- 取消前未提交供应方的任务立即释放；已运行任务显示取消结果。取消后返回的产物不得自动应用，按已公示的“可取消/不可撤销”规则处理，不临时改变收费口径。
- 断网/超时状态为“结果确认中”，先对账再重试；支付/扣费/退款异步回调重复到达不能重复入账。
- 积分账单显示报价、冻结、实扣、释放、退款、关联任务、时间与状态；用户能从任务进入账单，从账单定位任务。

### 8.3 验收
重复点击只创建一次付费请求；切换网络/杀进程不重复扣款；可用产物入库失败可恢复；取消后无静默应用；免费额度耗尽不会无授权扣积分；退款/部分成功账实一致。

## 9. 十二类状态与恢复
|状态|产品内容与操作|
|---|---|
|首次使用|选择创作目的、免费/预算偏好和示例任务；高级协议隐藏，可跳过引导|
|正常|当前项目/对象/图、连接/任务状态、主行动和最近变更可见|
|加载|展示真实阶段及可取消边界，允许离开页面，不能伪造百分比|
|空内容|提供示例、创建/导入入口，不自动购买或生成收费内容|
|无结果|保留检索词和筛选，给清除筛选及兼容节点/资源建议|
|未登录|本地编辑可继续，云服务保留草稿，登录后回到原任务|
|无权限|说明哪项项目/资源/服务权限不足，允许申请或另存有权限副本，不泄露私有内容|
|离线|本地能力可用；云操作可保存草稿或主动排队；在线游戏提示重连与安全退出|
|错误/超时|显示可理解原因和定位、重试/改配置/返回，保留草稿；付费任务先对账|
|重复操作|显示原任务/业务号及当前结果，不新建重复请求、图事务或扣费|
|中断|恢复选中对象、输入、任务和已提交版本；未完成事务不写入半成品|
|成功|显示实际完成内容、资源/工作流/账单入口和可撤销范围，不把模拟结果称为真实连接/发布|

所有状态适用于中/英/日/韩界面。用户消息、项目名称、接口路径、变量、JSON和代码标识不自动翻译。界面语言切换不得发起新任务或改变业务数据。

## 11. 统一规则补充
完整事务立即进入恢复日志；未落盘事务最晚2秒内保存，不因持续编辑无限推迟。切后台、正常关闭和导出前立即保存，持久化成功才显示已保存。每10分钟及高影响变更生成恢复点，保留最近20个且允许锁定。首次向导只问玩法、视角、联网模式、模板，操作方式随模板默认。
不可取消的媒体任务在启动前说明；运行入口显示“停止等待，后台继续”，可用产物交付收件箱才结算，未交付则释放/退还，不自动应用迟到结果。对话停止后的有效用量另行结算。
原始TCP/UDP的标准H5目标使用显式网关，APK的H5容器须声明目标原生桥；MQTT浏览器通道采用WS/WSS，gRPC采用gRPC-Web/代理并显示流差异，Socket.IO协议版本匹配；两个小游戏分别按适配器与目标版本判断，不互相继承能力。
