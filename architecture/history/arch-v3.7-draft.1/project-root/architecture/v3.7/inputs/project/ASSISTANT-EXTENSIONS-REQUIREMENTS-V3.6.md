# V3.6 AI开发助手扩展与自带模型需求

本附件补充完整V3.5需求。来源为用户在2026-11-14当前对话提出的MCP、Skill、自定义LLM地址/API Key、OpenAI双API、Claude Code双接入和OpenCode Go。用户未授权任意工具绕过工作流、读取全部设备资料或改变费用来源。需求定义为完整目标，原型实现范围另列。

## 1. 用户价值、入口和范围

零开发经验用户可以沿用平台默认助手，不配置扩展即可创作。需要外部资料、数值策划规范、自有模型或团队工具时，在设置→AI开发助手管理模型服务、MCP工具、Skill技能与活动记录；对话输入区显示当前模型、启用的扩展及修改入口。高级表单折叠。Android与Windows/macOS/Linux编辑器同语义，中英日韩UI不改用户内容。

用户自带模型由用户持有的供应商账户结算，平台服务使用平台积分；分别列出来源、账单方、估算可信度和实际用量，不静默互切或重复扣积分。平台内免费模型、平台付费服务、用户自带Key和用户Go账户是独立来源。免费或Go资格、模型目录与额度由供应商返回，产品不承诺永久免费或通用API资格。

优先级P0：模型地址/Key、协议选择、MCP与Skill配置、作用范围、对话内选择及工作流边界。P1：团队分发、目录订阅、版本批量更新。P1不删除完整需求，只描述实现排序。复用现有设置、语言、项目版本与工作流审阅；新增设置管理与兼容适配的成本，不编造工时或用户转化数据。

## 2. 模型服务

每项有稳定ID、显示名称、服务来源、API格式、Base URL、模型ID/别名、模型能力、鉴权方式、凭据引用、默认作用范围和状态。允许添加、编辑、复制、停用、移除、选择当前会话模型、设置项目/全局默认。项目覆盖全局时显示来源，重名不覆盖ID；会话快照在发送时确定，新设置从下一轮生效。移除被使用配置前显示引用并选择替代项，运行中的轮次可停止或继续原快照。

API格式与服务品牌分开：

| 预设 | 线路/鉴权 | 规则 |
|---|---|---|
| OpenAI Chat Completions兼容 | /v1/chat/completions；Bearer | 处理messages、tools/tool_calls、流式工具参数与usage。 |
| OpenAI Responses兼容 | /v1/responses；Bearer | 处理input/output items、function_call/output、流式事件、终止状态与usage；不能只换路径不换消息格式。 |
| Claude / Claude Code：API Key | Anthropic Messages /v1/messages；x-api-key | 发送明确API版本并保留需要的工具调用/思考签名/缓存字段。 |
| Claude / Claude Code：Bearer | 同一Messages格式；Authorization: Bearer | 是第二种鉴权预设，不虚构为第二种消息协议；网关支持能力独立声明。 |
| OpenCode Go | 服务来源，底层可选Chat、Responses、Messages及Google格式 | 模型目录包含实际API格式，路由按格式生成。显示Go账户结算与限额，不当作免费模型。 |

Claude Code官方还有Bedrock、Google Cloud等上游格式；本次“地址+API Key”主路径明确采用Messages及上述两种鉴权。旧Text Completions /v1/complete若导入，标为旧纯文本兼容，不伪装现代工具调用模型；不得选作自动工作流执行模型。未知格式不猜测、不静默降级。

用户输入Base URL时可以带已有/v1，界面预览最终请求地址，避免/v1/v1；完整接口地址及自定义路径放在高级设置。切协议若地址仍指向其他格式，要求修改并保留草稿。地址禁止内嵌用户名、密码或Key查询参数。远程默认HTTPS，本机模型可用回环HTTP；局域网明文地址需明确展示传输性质并由用户选择。高级包含超时、上下文/输出限制、并发、重试上限、流式、模型映射、支持的参数与额外请求头；认证头由凭据管理，不能明文混入可导出的附加头。

连接检查分别展示地址/认证、模型访问、流式响应、工具调用和结构化输出结果；小额生成测试先显示预计范围与结算方。不把模型列表成功当成工具可用。遇401/403、429/配额、404模型或格式不匹配、超时/断流、无usage、上下文超限，定位原因并允许改配置；保留用户输入与项目，不能自动换到扣积分线路。模型不支持工具时可作纯讨论/规划，自动修改入口说明所需能力并提供切换。

OpenCode Go端点模板以2026-11-14官方文档为依据：/inference/go/openai/v1、/inference/go/anthropic/v1以及Google格式路由；旧/zen/go/v1导入保留原值并给出迁移预览。具体模型能力/权限以服务返回为准；请求使用真实GameGen/OpenCode会话身份与工具语义，不伪造别的客户端。只用于创作开发助手，不把用户Go账户放进导出游戏给玩家调用。

## 3. API Key与请求归属

可输入、更换、清除Key；默认遮罩，仅明确操作时短暂显示。Android使用系统Keystore封装的安全凭据存储，桌面使用系统凭据服务；Linux缺少可用凭据服务时可选择仅会话保存，禁止静默回退明文。项目文档、历史、工作流、分享包、导出游戏、错误日志、截图样例与云同步均不包含Key。配置导出只保留无敏感信息的地址、模型和格式；导入后在设备上重新授权。

默认用户自带Key由本机编辑器直连用户选择的地址，原生网络层不依赖浏览器CORS。若提供平台代理，必须作为独立选择告知密钥和项目上下文的传输目的、接收方与保存规则，不默认代存用户Key。平台供应商Key继续只在平台服务端。接口返回的鉴权原文和供应商错误先脱敏再入活动记录。跨域重定向不携带认证头；认证目标域发生变化时重新确认。若走平台代理，用户地址不能访问平台内网或云元数据地址；本机回环能力仅由用户设备上的原生网络层处理。

## 4. MCP工具

每个连接包含ID/名称、来源/说明、版本、作用范围、连接方式、授权状态、工具目录、可读取项目范围、允许动作、超时与能力摘要。支持远程Streamable HTTP；服务明确提供旧SSE时显示兼容类型；本地stdio使用可执行文件与参数数组、工作目录、环境变量凭据引用。禁止将命令字符串直接交shell。Android本地服务受应用沙箱和已安装兼容运行时约束，检测缺失依赖后显示安装/替代远程入口，不能声称手机能直接运行桌面二进制。

添加→查看来源/权限→输入/导入配置→检测依赖与连接→展示真实能力→选择启用范围。远程OAuth支持授权、重新授权、撤销，API Key/Bearer/额外头使用凭据引用；换域或权限扩大后重新确认。工具支持tools/resources/prompts按需发现与搜索，不把所有工具说明一次塞满上下文。连接状态有停用、连接中、可用、需授权、缺依赖、不支持、超时/错误、离线；恢复只恢复此前启用且权限未扩大的连接。

同名工具用服务ID命名空间；缓存绑定服务配置/目录版本，变更提示受影响工作流或会话。编辑配置保留运行任务快照，停用可取消待执行调用；执行中的外部操作不谎称回滚。外部写入、费用、发布、破坏性动作按动作级授权展示目标与参数；仅已授权范围可自动执行，不能让Skill文字充当授权。

工具只通过GameGen受限能力代理进入OpenCode：读取选定资料、生成资源建议、提供合法节点/参数/契约提案。对项目的修改必须形成事务补丁、差异预览和可撤销记录；AI生成的客户端/服务端可执行逻辑仍只能是工作流。MCP服务不得获得绕开核心校验的项目文件直写通道。

## 5. Skill技能

提供内置游戏策划、数值、地图/关卡、RPG任务、SLG经济与接口契约技能模板；用户也可选择SKILL.md/技能目录、粘贴内容、导入安全包或从指定来源安装。展示名称、描述、何时使用、来源/作者/许可证、版本/内容哈希、正文、引用附件、依赖MCP/模型能力、支持语言和权限。先预览，再启用；不因导入即全局启用。

用户可新增/编辑/复制/停用/删除、设为手动或按描述自动匹配；对话中可显式选Skill，不要求新手学习路径语法。默认只加载名称/描述，匹配后按需读取正文和参考，调用记录显示实际版本与选择原因。版本更新先展示差异，保留原版本并可回退；重名来源并存，不静默覆盖用户手改。

支持OpenCode SKILL.md与目录结构，适配锁定的OpenCode版本，兼容目录在导入预览中明确优先级。附件只能在授权技能包内解析，阻断越界/符号链接逃逸、超大包和不支持格式。脚本、插件和可执行附件不因Skill启用而自动执行；需要使用时走单独受限工具与权限，不进入游戏逻辑。Skill指令不能覆盖产品规则、费用与授权；无法将自然语言/脚本包装为任意代码节点。依赖缺失显示修复路径，保留草稿。

## 6. 作用范围、会话和记录

配置定义可以全局复用；项目决定允许哪些模型/MCP/Skill，会话可在项目允许范围内临时调整。显式会话选择优先于项目默认，再到全局；不能扩大项目权限。凭据只按设备/账户授权，不随配置分享。停用和移除必须区分，删除配置不会删除已经生成的合法工作流。

对话发送时固定项目/会话、模型配置版本、扩展版本、工具目录、权限与费用来源。工具请求、Skill载入、用户授权、结果/错误、持续时间、模型Token用量和最终工作流事务ID可追溯；摘要默认显示，详情按需打开。日志脱敏、可清除/导出、保留策略可配置。离线时本地可用扩展继续，远程显示离线；本地引擎/项目手工编辑不被阻断。不能将浏览器配置检查记录写成真实模型/MCP调用结果。

## 7. 十二类状态

| 状态 | 内容、动作与恢复 |
|---|---|
| 首次使用 | 默认助手可直接用；扩展默认不启用；显示添加模型/MCP/Skill入口。 |
| 正常 | 显示生效配置、来源/范围/能力；可编辑、停用、选择与看记录。 |
| 加载 | 连接/目录/授权/导入解析有进度与取消；不覆盖旧完整配置。 |
| 空态 | 分类无配置时给出清楚添加入口，不伪造已安装能力。 |
| 无结果 | 搜索无匹配保留筛选词，清除筛选返回已有列表。 |
| 未登录/未授权 | 本地设置仍可编辑；仅受影响远程能力要求重新授权。 |
| 无权限 | 指出受限工具/目录/动作，可改范围或继续允许部分，不能全部开放。 |
| 离线 | 本地可编辑；已安装本地能力按能力运行，远程不能假装连接。 |
| 错误/超时 | 标记字段/阶段和原因，保留输入；重试不产生重复费用或重复外部写入。 |
| 重复操作 | 保存按配置版本/ID幂等；冲突保留两份并由用户选择；不会覆盖手改。 |
| 中断 | 切页/旋转/锁屏保留草稿；安全凭据生命周期明确；外部已执行动作单独记录。 |
| 成功 | 显示保存/检测/导入具体结果与范围，区分配置成功、真实连接成功、模型调用成功。 |

## 8. 验收与交付身份

AC-051：MCP表单合法性、远程/本地类型、权限范围、编辑启停及配置重开保持；实际目录/连接测试在正式客户端按上述状态验收。
AC-052：Skill预览、编辑/导入、按需启用与依赖状态，附件/脚本不自动执行，手改与版本回退可追溯。
AC-053：对话内选择模型和扩展，发送固定无密钥快照，设置仅影响下一轮，所有业务逻辑补丁经过工作流校验。
AC-054：Chat/Responses/两种Messages鉴权预设正确；Go按格式解析路由，Base URL无重复版本段，不兼容输入有明确错误。
AC-055：Key不落项目/浏览器持久化/日志/导出；本原型仅会话暂存，刷新提示重填；正式客户端遵循系统安全凭据策略。
AC-056：自带账户与平台积分来源独立显示，不静默更换付费来源；记录真实配置操作，不能冒充真实AI或工具结果。
AC-057：手机/桌面四语、键盘/触控、异常与离线状态、表单草稿和返回上下文完整；翻译不改变模型ID、URL或用户Skill正文。
