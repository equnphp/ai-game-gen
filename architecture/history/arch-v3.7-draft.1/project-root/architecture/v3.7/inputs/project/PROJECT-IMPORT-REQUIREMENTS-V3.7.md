# V3.7 Windows 外部引擎项目导入与转换需求

版本：v3.7.2-three-engines；日期：2026-11-14；需求：REQ-038；验收：AC-058—AC-064。
来源：用户最新指定先支持Cocos Creator、LayaAir、Godot；其余引擎移出当前导入范围。
本文件定义完整目标需求，不是已实现兼容清单。执行状态 not_run；quality_verified=false；release_permitted=false。

## 1. 用户、价值与产品决定

面向已有游戏工程的创作者、迁移旧项目的团队以及接收他人项目的新手。用户不需要先学习目标引擎的文件结构：从“项目→导入引擎项目”选择源目录或源工程包，系统识别引擎与版本，展示能转换、需确认、需补齐的内容，再生成新的 GameGen 项目。

目标为可独立打开、修改和保存的 GameGen 原生项目：场景、地图、关卡、预制体、资源、数值、动画和工作流均进入现有统一文档/事务体系。新项目可通过对话与人工工作流继续修改，之后同步 Android，按现有四目标导出规则处理。Windows 是外部工程转换入口；Android 接收转换后的 GameGen 项目，不要求手机安装源引擎。

采用“按引擎和格式版本提供适配器＋统一转换中间模型”的方案。相比仅复制素材，保留对象、引用与可编辑结构；相比承诺任意工程一键无损，逐项给出转换结果与阻塞项。机会成本是持续维护不同引擎版本、节点语义及资产授权规则；不编造开发工期或市场数据。

沿用已有架构：自研 C++ 引擎、AI 可执行逻辑只能工作流；Cocos engine 仅参考，禁止作为运行时、SDK、源码、二进制、适配器或构建链依赖。这里新增的是独立读取用户工程数据并转换的能力，不改变该禁用决定。原格式读取器须独立实现并记录许可来源，不能复制受限引擎实现。

## 2. 固定引擎白名单

本产品的Windows工程导入只接收下表3类引擎，属于需求确定的范围，不代表导入器已经实现。选择依据是面向2D/2.5D创作、具有明确源工程结构、覆盖国内与国外常用2D工具，并控制格式与语义维护成本；不声称做过市场份额统计。

| 可导入的引擎 | 明确的源工程范围 | 要求转换的主要内容 |
|---|---|---|
| Cocos Creator | 2.4.x、3.x源工程，分代识别 | 资源元信息/UUID、2D场景、预制体、图块、动画、组件与事件绑定 |
| LayaAir | 2.x、3.x IDE源工程，分代识别 | 2D场景/预制体、资源、UI、动画、物理组件与逻辑绑定 |
| Godot | 3.x、4.x源工程，分代识别 | 项目配置、2D场景/节点、资源引用、信号、地图与动画 |

这3类构成封闭名单。版本范围仍须按实际源格式/子版本选择正确解析规则；同一引擎的未知新格式也不得套用旧规则强行创建项目。识别不在名单中的引擎时，直接显示“不支持该引擎项目导入”，不得生成空壳项目、猜成另一种引擎或进入通用映射向导。

当前不纳入：GameMaker、Construct 3、RPG Maker MV/MZ，以及Unity全版本（包括Unity 2D）、Unreal Engine全版本（包括Paper2D）、Cocos2d-x/Cocos Studio、Egret/EUI、Defold、GDevelop、Construct 2、Phaser、PixiJS及自定义H5工程。名单外引擎均不纳入本需求，没有“其他引擎”“自定义引擎”“通用工程”“导出中间包后也可导入”的兜底承诺。

不按一次项目的文件大小临时决定引擎是否纳入：小型Unity/Unreal项目同样排除；白名单引擎的大资源项目则按磁盘空间、任务与恢复规则处理。仅转换2D/2.5D范围，白名单引擎自身的完整3D功能不进入本产品范围。

导入入口统一命名“导入引擎项目”，引擎选择框固定3项；自动识别也受同一名单约束。白名单源工程中缺少必需数据、格式不受支持或文件为发布产物时，应明确指出缺少的源数据，不自动启动原编辑器、补装SDK或运行工程。通用图片/音频/字体等素材导入仍属于既有资源功能，不是名单外引擎项目导入入口。

当前实施范围只有Cocos Creator、LayaAir、Godot这3类，不保留第二批引擎承诺；未来是否增加须另行提出需求并更新范围。导入器必须逐项声明精确的源格式版本、对象类型、转换等级、限制与适配器版本；不因排序省略任一类已声明需求。

## 3. 导入操作与任务结果

1. 选择源目录/工程包，显示只读来源、目标位置、引擎识别结果和版本；可人工纠正识别但必须重新分析。
2. 本机读取工程清单与引用，列出场景、地图、资源、组件、脚本、插件、外部依赖、缺失文件和许可信息。此分析不得运行源项目。
3. 默认推荐“全部可用内容＋保留原工程”。高级展开可按场景、资源类型、关卡及依赖筛选；依赖会随引用补选，不能留下假完整工程。
4. 显示转换预览：自动转换、需用户确认的替代、需补齐的逻辑、不能转换；显示对象定位、原因、替代方式、目标磁盘空间与预计数据量。
5. 用户确认后在暂存位置生成 GameGen 数据，先检查文档/引用/节点规则，再原子登记新项目。取消、断电、磁盘不足或格式错误不能覆盖原工程、旧目标项目或已提交的 GameGen 版本。
6. 完成页分别展示“项目创建结果”“内容转换报告”“试玩/发布阻塞项”。可打开场景、定位工作流待补项、查看原对象对照、继续处理或回到项目列表。

任务状态为分析、待确认、转换中、暂停/中断、失败、项目已创建。内容状态按对象分别为已转换、已确认替代、待补齐、已明确排除。运行就绪必须满足：必需依赖存在、必需逻辑已用合法工作流表达、目标能力满足。只有创建文件成功时，不能提示“全部迁移完成”。

## 4. 内容与语义转换规则

| 内容 | 必须保留/转换 | 不能等价处理时 |
|---|---|---|
| 工程与对象身份 | 新projectId；源对象ID→GameGen稳定ID映射；依赖图、来源版本、适配器版本 | 冲突/重复ID定位，禁止仅按文件名匹配 |
| 场景/预制体/UI | 层级、实例/覆盖、变换、锚点、可见性、排序、相机、分辨率适配、文字及输入映射 | 明确替代或占位；关键交互缺失记为阻塞 |
| 2D与2.5D地图 | 图层、图块、方格/六边格/等距参数、地形高度/通行面、碰撞、出生点、传送点、关卡目标 | 原引擎不存在的语义不能凭空推断；待用户映射 |
| 图像/图集/音频/字体 | 原始资源及引用、裁剪、旋转、采样/混合、九宫格、音频事件、字体回退与许可 | 缺原文件/不支持编码/授权不明分别提示；不自动上网补下载 |
| 帧/骨骼/粒子动画 | 动画片段、时间轴、事件、骨骼/插槽、材质与粒子参数中可映射部分 | 声明格式/版本及运行库授权边界；复杂效果提供显式替代 |
| 物理 | 形状、刚体、碰撞组、触发器、关节、重力/时间步等已支持语义 | 区分像素/米、坐标方向、质量/角度单位；不把近似结果登记为等价 |
| 数值/剧情/任务 | 字段类型、枚举、变量作用域、表引用、条件、奖励、分支及本地化键 | 无对应字段走映射向导；不能把玩家存档混为设计数据 |
| 事件/代码/可视化逻辑 | 已知模式映射为受限工作流，附源对象/位置与目标节点对照 | 按第5节补齐，禁止任意代码节点 |
| 材质/插件/平台能力 | 映射内置2D材质、能力与API契约；凭据重新设置 | 特殊shader、原生插件、SDK和第三方服务不得被静默打包执行 |
| 原生3D | 可复用2D资产/正交画面数据经用户选择进入2D/2.5D范围 | 不声称把任意3D关卡无损变成可交互伪3D；完整3D保留为迁移说明 |

转换报告不使用一个模糊百分比掩盖丢失。分别统计对象、资源、引用、行为与阻塞项：总数=已转换+已确认替代+待处理+明确排除。每项有严重级别、源对象、目标对象、规则版本、原因、处理动作及确认记录。未知对象不得静默丢弃，报告必须可在本机导出。

## 5. 脚本、AI与工作流

白名单工程中的JS/TS、GDScript、Godot C#及事件指令只作为不执行的迁移输入。已知生命周期、输入、定时、碰撞、状态切换、数值与API模式可由本机规则转换；动态反射、任意库调用、线程或未支持行为生成待补任务，列出输入/输出、原位置与用户可选意图。

未知逻辑不得用“执行源代码”节点、原引擎运行时或隐藏脚本绕过规则。候选工作流经过与人工/对话相同的类型、权限、引用、客户端/服务端域及版本校验；人工改好的图继续作为后续对话的唯一基线。

本轮“本地资源不上传云端”是强约束：转换、清单、原代码、资源、缩略图、报告和路径不自动发送给云模型、远程MCP、遥测或错误收集。可用的本地模型可提出工作流候选；没有本地模型时仍能用规则与人工完成处理。导入向导不把云端模型作为必需步骤，也不能静默扣积分。

## 6. 文件、来源与重导入

只读取用户选定目录及明确授权的外部依赖；拒绝越界路径、包内路径逃逸、危险符号链接、不支持的加密/损坏包。不会执行源工程构建脚本、安装包管理依赖、加载插件或运行导入钩子。源项目中的Key、签名证书、缓存、构建产物、设备路径和账号设置不进入目标项目。

资源内容采用contentHash去重，assetId仍独立表示逻辑身份；来源ID、相对路径、许可证/归属、来源哈希和映射规则可追溯。不得通过去重把不同授权范围的资源错误共享。没有再分发权限的资产可以提示本地使用限制，阻断相关分享/导出，不宣称转换改变原素材许可。

首次导入创建新项目。再次导入区分“另建项目”和“更新已有迁移项目”；更新以“上次导入基线/当前GameGen修改/新源版本”三方比较。源改动、GameGen手改、源删除/重命名及映射规则升级逐项审阅；同一对象双方改动保留冲突版本，不按时间戳覆盖。源脚本参考副本单独保存在本机迁移资料，不进入游戏执行包，也不默认进入设备共享包。

## 7. 权限、隐私与范围

导入本地工程无需登录平台、互联网、ADB或积分。只授予选定文件读取权与目标目录写入权；目标项目创建后有自己的访问权限。导入器不能取得平台供应商Key、MCP凭据或任意目录访问权。产品内容localOnly约束传播到对话上下文、插件、远程工具及诊断导出，不能被Skill文字覆盖。

本需求仅接受第2节3类白名单源工程，排除该节列明的引擎及所有未列引擎；不包含从APK/EXE/小游戏成品反编译还原工程、破解加密资源、自动购买资产、原样执行任意原引擎代码、回写原引擎工程或完整3D迁移。现有H5/APK/微信小游戏/抖音小游戏目标不因源引擎支持平台更多而扩张。

## 8. 页面与十二类状态

新增Windows页面：导入入口、来源/版本、内容分析、映射/兼容报告、转换进度、结果/待补工作流、重导入冲突。四语同语义；默认只显示推荐方案与阻塞项，高级映射按需展开。Android仅增加接收后打开项目及查看迁移报告入口，不提供外部源工程转换向导。

| 状态 | 进入、内容与操作 | 退出与恢复 |
|---|---|---|
| 首次使用 | 无迁移历史，说明源工程只读，选择目录或工程包 | 选择后分析；取消回项目页 |
| 正常 | 显示引擎、版本、映射、选择和报告 | 可确认创建或返回编辑范围 |
| 加载 | 分析/转换阶段、已处理量、取消/暂停入口 | 完整阶段结束才更新结果；未完成内容留暂存 |
| 空态 | 源目录为空或无可导入内容 | 换目录；不生成空壳假成功 |
| 无结果 | 筛选无对象/不支持识别 | 清除筛选或改选白名单源工程；未列引擎明确拒绝 |
| 未登录/未授权 | 平台未登录不阻断；文件授权失效显示具体目录 | 重新授予选定文件权限或取消 |
| 无权限 | 目标不可写、依赖不在授权范围 | 换目录/选依赖；不扩大到整盘 |
| 离线 | 无互联网仍执行本机转换 | 缺远程依赖列待补，允许用户选择本地文件 |
| 错误/超时 | 错误定位到格式/文件/阶段，保留选择与报告 | 重试失败项、改映射或取消；不覆盖原件 |
| 重复操作 | 双击导入、重复包、同名目标 | 同任务幂等；选另建或三方更新，禁止自动覆盖 |
| 中断 | 关闭、睡眠、崩溃或空间不足 | 本机恢复任务/重新分析变更输入，旧完整项目可用 |
| 成功 | 项目创建与转换完整性分开展示 | 打开、定位待补项、导出报告或通过局域网发送 |

## 9. 可验收目标

- AC-058：引擎选择和自动识别仅接受第2节3类白名单；Unity/Unreal及名单外工程明确拒绝，无通用工程/中间包兜底；未知格式不误称支持，源项目保持原样。
- AC-059：支持内容转成GameGen原生文档/资源及稳定引用；移开源工程后仍可打开编辑；必需缺失明确阻塞，不只复制素材。
- AC-060：每个源行为有转换/替代/待补/排除记录；可执行业务逻辑只为合法工作流；对话与人工继续修改同一项目。
- AC-061：语义、缺失与许可逐项报告，统计可对账；不把项目创建成功等同完整迁移或运行就绪。
- AC-062：失败/取消不损坏原件及已提交项目；重导入保留三方冲突和手改；重复请求不重复覆盖。
- AC-063：不执行源工程钩子/脚本、不自动联网下载、不向云端发送导入内容或凭据；本机规则和人工流程不依赖云模型。
- AC-064：转换后的项目按统一格式在Windows/Android继续编辑和使用既有四目标导出流程；资源与引擎许可/目标限制仍生效。

以上为验收定义，execution_status=not_run。没有导入器运行、目标引擎样本或人工批准证据。
