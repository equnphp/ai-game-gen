# 游戏类型与玩法模块完整需求 V3.5
日期：2026-11-14
本文件是主规格第4节的组成部分。目录按玩法家族组织，具体子类型可组合；每类必须有可玩的模板、配置、工作流和验收，不能只提供类型名称。

## 1. 统一模板规则
每个模板包含核心循环、输入方案、地图/关卡、玩家/敌人或交互对象、目标和结算、数值、资源许可、存档策略及可定位的工作流。新手只改目标、外观、难度与常用数值；其余按模板默认，高级面板编辑同一内容。
选择类型不锁死地图投影或联网模式；与玩法确实不兼容的选项显示原因和变更影响，不能静默切换。操作方式由模板预设，用户在更多设置修改。
模板预设所有随机行为可记录种子；排行榜、奖励和联网结果使用项目配置的权威规则。试玩不得写入生产排行榜或正式经济。
切换/组合类型先列出复用、增加、冲突和删除项，旧内容默认保留；有互斥规则时选择优先级或明确分场景，事务整体撤销。

## 3. 组合玩法规则
1. RPG+SLG：角色战斗与建筑队列共享物品/资源定义，角色进度、关卡实例、公共世界与城市状态分开存储；奖励和建造走同一原子经济规则。
2. Roguelike+卡牌：随机候选、卡牌实例、牌组变化及本轮种子绑定同一轮挑战，死亡后按局外成长配置保留，不将整副临时牌组写入永久账户。
3. 等距+战棋/经营：高度、楼层、可见性、占地和道路按地图需求执行；地图看起来重叠不等于相邻或可攻击。
4. 节奏+动作：音乐时间与动作逻辑时间明确映射；变速/暂停由项目规则统一，不各自修改时钟。
5. 多人+任何类型：共享状态、个人状态、隐藏信息和经济权限明确；单机暂停、重开和撤销不能直接用于公共服务器状态。
6. 自定义规则使用现有结构化模块和受限工作流表达；缺少平台节点时生成可审查的能力需求说明，不能塞进任意脚本继续执行。

## 4. 模板参数与新手操作
每种模板第一屏给出一句核心玩法、操作示意和“立即试玩”；对话可直接引用主角、目标、失败原因及关卡。
作者可编辑难度预设；修改后显示影响数值，不在后台偷偷调难度。提供恢复模板默认与只恢复当前字段，两者的作用范围清楚。
模板有资源替换槽、声音槽、目标和行为入口，换美术不删除碰撞和工作流。高级面板包括数据、动画、地图和网络引用，隐藏后仍保留。
关卡/数值/种子/脚点等模板参数均可AI与人工交替修改，版本记录显示来源。对模板更新先比较，不重写作者自定义。

## 5. 验收 AC-047 / TEST-047
- TYPE-AC-01：每个家族至少提供一个可玩的代表模板；目录项显示其玩法、输入、地图视角、模块、素材与目标，不能只创建名称空工程。
- TYPE-AC-02：每个模板均完成“进入→操作→目标推进→胜败/阶段结算→重试/继续→保存恢复”，同时覆盖本表对应异常。
- TYPE-AC-03：类型与视角/联网可组合，冲突有原因与可审查的替代；取消类型变更保持原工程。
- TYPE-AC-04：新手改变外观、目标、难度和一个行为后可继续高级修改；AI再修改不丢手工规则。
- TYPE-AC-05：随机、经济、时间与隐藏信息遵守对应模块；不以客户端画面排序替代规则。
- TYPE-AC-06：跨目标导出按目标能力显示兼容情况，类型选择不会取消目标检查或改变费用授权。
