## 2. 架构必须交付的细化内容

| 责任模块 | 所需契约与边界 | 产品验收关联 |
|---|---|---|
| 外部工程适配器 | 仅6类白名单的版本能力目录，纯数据读取、依赖清单、中间模型和独立许可边界；无名单外中间包入口，不执行原工程/不依赖Cocos SDK | AC-058、063 |
| 映射与工作流迁移 | 稳定来源ID映射，坐标/单位/默认值规则，图节点语义及未知逻辑任务；转换等级与运行阻塞分开 | AC-059—061 |
| 导入任务与重导入 | 输入快照、暂存/原子创建、三方基线、冲突/取消/恢复、重复请求和磁盘空间模型 | AC-062、064 |
| 平台发现适配 | Android NSD/权限、Windows发现/接口/防火墙；mDNS/DNS-SD与手动连接，局域网选路及无公网回落 | AC-065、072 |
| 配对与本机接收服务 | 设备身份、首次信任、短码/二维码方案、会话认证、范围授权、撤销和密钥生命周期 | AC-066、070 |
| 同步引擎与资源库 | 单一存储所有者的一致快照，差异清单、contentHash去重、依赖、续传、整体校验、事务提交和多会话排队 | AC-067、068 |
| 合并与试玩交互 | 共同祖先/分支身份、三方领域比较、删除标记、用户冲突选择、固定试玩版本与手机修改接回 | AC-069、071 |
| 内容策略与宿主 | localOnly贯穿AI上下文、MCP、备份/日志；凭据不迁移，Android后台生命周期与Qt/Android薄表现层 | AC-063、070、072 |

以上是待架构细化的模块职责，不是新增独立微服务。默认编辑器模块化单体：格式读取、映射、同步、资源与事务共用C++领域核心；Qt和Android只承接文件授权、发现/网络/凭据等平台适配及界面。内嵌局域网接收服务是本机进程能力，不需要云资源服务器。

推荐通信关系为“mDNS/DNS-SD发现→本地配对/能力协商→TLS保护的控制与内容传输→本机快照差异/校验→核心事务提交”。可使用WSS传递控制/进度和HTTP分块传内容；应由架构说明必要性、替代和版本演进，不能把推荐路线冒充已实现协议。

必须复用现有projectId/documentId/objectId/assetId、revision、contentHash、事务和ProposePatch/CommitProposal等语义。跨设备revision不同分支不能直接比大小，源端快照不能用原始数据库/WAL拷贝代替。新协议必须版本化，并提供取消、幂等、回滚/恢复、错误码和兼容迁移。

## 3. 产品决策与技术问题路由

已闭合的产品解释：
- 导入名单固定：Cocos Creator、LayaAir、Godot、GameMaker、Construct 3、RPG Maker MV/MZ；Unity/Unreal（包括2D路径）及全部未列引擎排除。
- 导入优先生成新项目；再次迁移可显式三方更新，源工程不变。
- 未知逻辑生成待补任务；必需逻辑不完整时不声明运行就绪。允许可编辑草稿，不允许隐式执行原脚本。
- 缺少本地模型时仍有规则与人工路径；不允许上传工程求云模型转换。
- 局域网默认手动同步、双端确认和限定范围；双向/自动模式需明确开启，冲突和删除不能自动覆盖。
- 资源库共享按选定内容/依赖授权；API Key、签名、设备密钥与私人历史不随项目传递。
- 本轮不是云协作、实时多人同编、跨公网组网或远程擦除功能。

架构应回答并写回其新版文档的事项：
1. 仅针对6类白名单明确格式版本、纯数据解析和兼容演进；不得新增其他引擎/通用工程/中间包兜底入口。
2. 设备身份/配对密码学方案、TLS信任与轮换、Android系统/target SDK权限矩阵、Windows入站范围和IPv6/多网卡行为。
3. 分块、队列、任务并发、存储预算与恢复点；发现时延/内存/吞吐等可度量技术阈值及适用环境，不编造已测值。
4. localOnly策略与现有云模型、远程MCP、错误上报的拦截位置及失败关闭行为。
5. 受限二进制工程、未知组件、骨骼资源/字体/插件授权限制的用户可选路径，确保必需依赖无强制商业购买。

路由：架构问题→产品/用户；UI问题→产品；前后端技术问题→架构。上述技术问题不阻止本轮需求文档交付，但阻止未经细化就宣称开发交接完成。没有模拟接收方答复或批准；实际角色确认须绑定新版本和哈希后登记。

## 5. 验收定义与独立质量交接

产品给出15条Given/When/Then验收定义，全部not_run；不是实际测试结果或独立质量计划。质量角色按以下八类细化前置条件、步骤、数据、环境与责任人：
1. 功能：每类引擎、转换等级、同步模式和十二状态。
2. 契约/数据：来源ID、工作流、资源引用、协议版本及事务幂等。
3. 集成/回归：导入→手机编辑→接回电脑；现有对话、地图、物理、动画、导出约束。
4. 性能/容量：大工程、大音频、多小文件、去重、空间预算和队列；阈值由架构提供。
5. 安全/隐私：不执行源代码，包路径边界，配对/撤销，局域网选路，凭据与云传输阻断。
6. 可访问性/四语/设备：键鼠触控、屏幕/旋转、权限与系统版本、输入/读屏及四语不改用户内容。
7. 恢复：中断/改源/磁盘满/损坏块/崩溃、冲突、旧版本与清理边界。
8. 业务任务与验收：新手导入、首次配对、转移试玩、手改保留和完整性报告可理解性。

本轮这些类别都适用，没有把难项标为不适用。实际质量计划、原生构建、性能、安全、设备和故障演练均未执行，且本轮用户没有要求执行自动化。代码基础自测也不因后续计划标志而被授权执行。
